# PokeWalker — 포켓워커 (HGSS, 2009) 데스크탑 펫

macOS 플로팅 포켓워커. 의존성 0, Swift 6 + AppKit, `swiftc`만 사용. 스프라이트는 **실제 포켓워커 도트**(HGSS ROM에서 추출된 것) — 흑백 원작 화면, 또는 HGSS 공식 팔레트로 칠한 **컬러** 화면(기본), 코스·출현표·도구표는 원작 20개 코스 그대로.

```sh
./build.sh        # 빌드 + 셀프테스트 + PokeWalker.app 조립
./build.sh run    # 빌드 후 (재)실행 — 실행 중인 인스턴스를 죽임
open PokeWalker.app
```

## 걸음 = 키 입력 + 클릭

Mac엔 만보기가 없으니 **키 누름·마우스 클릭 1회 = 1걸음**. 시스템 입력 카운터(`CGEventSource.counterForEventType`)를 읽기만 하므로 손쉬운 사용/입력 모니터링 권한이 필요 없고, 무엇을 입력했는지는 알 수 없음(횟수만). 같은 로그인 세션이면 앱을 꺼둔 동안의 입력도 다음 실행 때 합산.

20걸음 = 1W (최대 9999W). 자정에 오늘 걸음이 기록으로 넘어감(최근 7일).

## 조작 (◀ · ● · ▶ + 아래 ⌂ 홈, 또는 ← / return·space / → / esc)

- **화면 클릭**도 됨: 메뉴·카드·도구 화면은 왼쪽 1/3 = ◀, 가운데 = ●, 오른쪽 1/3 = ▶ / 레이더·다우징은 풀숲을 직접 클릭 / 배틀은 기술 이름 클릭 / 메시지는 클릭하면 넘어감. 그 외 빈 곳은 드래그.
- **홈**: ◀/▶ → 메뉴. ⌂(esc)는 어디서든 홈 — 배틀 중이면 도망. 메뉴 끝에서 한 번 더 넘기거나 20초 방치해도 홈.
- **포켓 레이더** (10W): 풀숲 4개 중 하나가 1.5초 뒤 흔들리며 `!` — 2초 안에 커서를 옮겨 가운데. 성공하면 배틀.
- **배틀**: 무대엔 한 번에 한 마리만 원래 크기로(공격하는 쪽이 돌진 → 맞는 쪽이 흔들림·깜빡임, 급소는 화면 반전). 볼은 포물선으로 날아가 붉은 빛으로 빨아들이고, 2~3번 흔들린 뒤 딸깍(별) 또는 튀어나옴. 서로 HP 4. 공격(80% 명중, 1/8 급소 2뎀) / 피하기(상대 공격 회피, 가끔 도망감) / 볼(HP 4→20% … 1→80%, 실패 시 1/4 도망) / 도망. 쓰러뜨리면 못 잡음 — 약하게 만들어 잡기.
- **다우징** (3W): 풀숲 6개, 2번 기회. 빗나가면 `가깝다!`(옆 칸) / `멀다...`.
- **커넥트**: 워커의 포켓몬·도구를 상자/가방으로 보냄(워커는 각각 3개까지, 넘치면 바로 상자로).
- **트레이너 카드**: 코스·오늘/합계 걸음·일수·도감 / 최근 7일 그래프.
- **포켓몬 · 도구**: 워커에 들고 있는 것.

우클릭 = "게임 쪽": 코스 변경(누적 W로 해금 — 원작 수치), 함께 걷기(상자의 포켓몬과 교체), 가방, 크기(×2/×3/×4), 기기 색(몬스터볼/슈퍼볼/하이퍼볼/마스터볼), 화면(컬러/원작/백라이트), 종료. 코스·포켓몬을 바꾸면 커넥트 후 새로 페어링(코스 걸음 0부터).

## 규칙 (원작)

- 코스마다 그룹 A/B/C 각 2마리, **페어링 때 그룹마다 1마리**가 골라져 워커에 실림.
- 레이더 추첨: 희귀한 A부터 "코스 걸음 ≥ 필요 걸음 이고 확률 당첨"이면 그 포켓몬, 아니면 다음 → C는 보장. (Serebii 표의 퍼센트가 이 방식으로 정확히 재현됨: A 70 → B (1−.7)×75 = 22.5 → C 7.5)
- 도구도 같은 방식(희귀한 것부터, 상처약류가 보장).
- 함께 걷는 포켓몬이 코스의 특기 타입 3개 중 하나면 필요 걸음 25% 감소(4세대 타입 기준).
- **이로치**: 레이더에서 만난 포켓몬이 1/128 확률로 이로치(4세대 원작은 1/8192 — 여기선 하루 몇 판이라 너무 희박, `Walker.swift`의 `shinyOdds`). `✦ 반짝! ✦` + 배틀 중 반짝임, 목록엔 ★. 이로치 색은 HGSS 일반/이로치 스프라이트의 픽셀 대응으로 만든 종별 팔레트. 원작 포켓워커엔 없는 요소.
- 원작과 다른 점: 레벨업/경험치 없음, 이벤트 코스 7개 없음, 레이더 연쇄 없음, 소리 없음.

## 파일

| 파일 | 내용 |
|---|---|
| `Walker.swift` | 규칙 엔진 + 저장 상태 + 배틀 + 저장/복구 (`Foundation`만) |
| `main.swift` | AppKit UI: 기기, 96×64 4계조 LCD, 화면들, 메뉴 |
| `Data.swift` | **생성됨** — 493종 한국어 이름·타입, 20코스 |
| `sprites.bin` | **생성됨** — 493종 × 2프레임 × 64×48, 2bpp 흑백 |
| `color.bin` | **생성됨** — 같은 도트의 컬러판, 종별 일반/이로치 15색 팔레트 + 4bpp |
| `fonts/` | Galmuri9·Galmuri7 (이민서, SIL OFL 1.1 — `fonts/OFL.md`). 닌텐도 DS 시스템 폰트를 본뜬 한글 도트 폰트, 원래 크기(10/8px)로만 써서 글자가 도트에 딱 맞음 |
| `tools/gen.py` | 위 둘을 원본(추출 스프라이트 시트, Serebii, PokeAPI)에서 재생성. Pillow 필요 |
| `Test.swift` | `PokeWalker --selftest` — 걸음/W/날짜/추첨 확률/배틀/저장/데이터 |

세이브: `~/Library/Application Support/PokeWalker/state.json` (+ `.bak`, 손상 시 `state.corrupt-*.json`). 창 위치·크기·색은 `defaults dev.khmin.pokewalker`.

코스 한국어 이름은 번역(공식 한국판 명칭 아님). 스프라이트·데이터 저작권은 Nintendo / Game Freak / The Pokémon Company — 개인 소장용, 저장소는 비공개로.
