# PokeWalker — 포켓워커 (HGSS, 2009) 데스크탑 펫

macOS 플로팅 포켓워커. 의존성 0, Swift 6 + AppKit, `swiftc`만 사용. 스프라이트는 **실제 포켓워커 도트**(HGSS ROM에서 추출된 것) — 흑백 원작 화면, 또는 HGSS 공식 팔레트로 칠한 **컬러** 화면(기본), 코스·출현표·도구표는 원작 20개 코스 그대로.

```sh
./build.sh        # 빌드 + 셀프테스트 + PokeWalker.app 조립
./build.sh run    # 빌드 후 (재)실행 — 실행 중인 인스턴스를 죽임
open PokeWalker.app
```

## 걸음 = 키 입력 + 클릭

Mac엔 만보기가 없으니 **키 누름·마우스 클릭 1회 = 1걸음**. 시스템 입력 카운터(`CGEventSource.counterForEventType`)를 읽기만 하므로 손쉬운 사용/입력 모니터링 권한이 필요 없고, 무엇을 입력했는지는 알 수 없음(횟수만). 같은 로그인 세션이면 앱을 꺼둔 동안의 입력도 다음 실행 때 합산.

20걸음 = 1W (최대 9999W). 자정에 오늘 걸음이 기록으로 넘어감(최근 7일).

## 조작 (◀ · ● · ▶ + 아래 ⌂ 홈, 또는 ← / return·space / → / esc)

- **화면 클릭**도 됨: 메뉴·카드·도구 화면은 왼쪽 1/3 = ◀, 가운데 = ●, 오른쪽 1/3 = ▶ / 레이더·다우징은 풀숲을 직접 클릭 / 배틀은 기술 이름 클릭 / 메시지는 클릭하면 넘어감. 그 외 빈 곳은 드래그.
- **홈**: ◀/▶ → 메뉴. ⌂(esc)는 어디서든 홈 — 배틀 중이면 도망. 메뉴 끝에서 한 번 더 넘기거나 20초 방치해도 홈.
- **포켓 레이더** (10W): 풀숲 4개 중 하나가 1.5초 뒤 흔들리며 `!` — 2초 안에 커서를 옮겨 가운데. 성공하면 배틀.
- **배틀**: 무대엔 한 번에 한 마리만 원래 크기로(공격하는 쪽이 돌진 → 맞는 쪽이 흔들림·깜빡임, 급소는 화면 반전). 볼은 포물선으로 날아가 붉은 빛으로 빨아들이고, 2~3번 흔들린 뒤 딸깍(별) 또는 튀어나옴. 서로 HP 4. 공격(80% 명중, 1/8 급소 2뎀) / 피하기(상대 공격 회피, 가끔 도망감) / 볼(HP 4→20% … 1→80%, 실패 시 1/4 도망) / 도망. 쓰러뜨리면 못 잡음 — 약하게 만들어 잡기.
- **다우징** (3W): 풀숲 6개, 2번 기회. 빗나가면 `가깝다!`(옆 칸) / `멀다...`.
- **커넥트**: 워커의 포켓몬·도구를 상자/가방으로 보냄(워커는 각각 3개까지, 넘치면 바로 상자로).
- **트레이너 카드**: 코스·오늘/합계 걸음·일수·도감 / 최근 7일 그래프.
- **포켓몬 · 도구**: 워커에 들고 있는 것. 포켓몬 페이지에서 ● = **그 포켓몬과 함께 걷기**(원래 동료가 그 자리로).
- **도감**: 만난(봤음) · 잡은(잡음) 포켓몬만 넘겨봄. 번호·이름·타입, 본 것만이면 실루엣.

## 레벨 · 진화

- **1걸음 = 경험치 1** (HGSS 포켓워커 원작 규칙). 종별 성장 곡선(4세대 경험치표), 경험치는 **포켓몬마다** 저장 → 동료를 바꿔도 각자 레벨 유지. 레벨 업은 홈 화면에서 알림.
- **진화**(4세대 방식을 워커에 맞춤, 데이터는 PokeAPI):
  - 레벨: 레벨 업 순간 조건(레벨·성별·낮/밤·가방의 도구·상자에 특정 포켓몬) 충족 시. 기술을 배워야 하는 진화(에이팜·왕자리 등)는 그 기술을 배우는 레벨로.
  - 친밀도(피츄·이브이→에브이/블래키·골뱃 등)·아름다움(빈티나): 함께 **10,000걸음** 걸은 뒤 레벨 업.
  - 장소: 이브이→리피아(숲 코스)/글레이시아(얼음 산길), 레어코일·코코파스(동굴 코스).
  - 진화의 돌: 우클릭 → **진화의 돌 쓰기**. 돌·진화 도구는 우클릭 → **교환소**에서 1000W (HGSS에선 포켓슬론 포인트로 교환하던 것). 달의돌은 다우징으로도 나옴.
  - 통신교환: 그 포켓몬과 함께 걷는 중 **커넥트** = 통신 (필요한 도구는 가방에).
  - 진화는 되돌리거나 취소할 수 없음(B 캔슬 없음). 껍질몬(Shedinja)은 없음.
