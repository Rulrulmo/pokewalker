# PokeWalker — 포켓워커 (HGSS, 2009) 데스크탑 펫

macOS 플로팅 포켓워커. 의존성 0, Swift 6 + AppKit, `swiftc`만 사용. 스프라이트는 **실제 포켓워커 도트**(HGSS ROM에서 추출된 것) — 흑백 원작 화면, 또는 HGSS 공식 팔레트로 칠한 **컬러** 화면(기본), 코스·출현표·도구표는 원작 20개 코스 그대로.

```sh
./build.sh        # 빌드 + 셀프테스트 + PokeWalker.app 조립
./build.sh run    # 빌드 후 (재)실행 — 실행 중인 인스턴스를 죽임
open PokeWalker.app
```

### 다른 Mac에 주기

```sh
./build.sh dist   # dist/PokeWalker.zip — Apple Silicon + Intel, macOS 13 이상
```

zip을 보내면 받는 사람은 압축을 풀고 `PokeWalker.app`을 응용 프로그램 폴더로 옮긴 뒤:
1. 처음 한 번은 **우클릭 → 열기 → 열기** (Apple 개발자 서명이 없어서 더블클릭하면 "확인되지 않은 개발자" 경고로 막힘).
   macOS 15 이상에서 우클릭 열기도 막히면: 한 번 실행 시도 → **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**.
   또는 터미널: `xattr -dr com.apple.quarantine /Applications/PokeWalker.app`
2. 알림 허용 물어보면 허용.

경고 없이 더블클릭으로 열리게 하려면 Apple Developer Program(연 $99)의 Developer ID 서명 + 공증(notarization)이 필요. 세이브는 사람마다 따로(`~/Library/Application Support/PokeWalker`).

## 메뉴 막대 · 알림

- 상단 메뉴 막대에 몬스터볼 아이콘 + 현재 W(알이 곧 부화하면 `·알`). **클릭 = 워커 숨기기/보이기**, 우클릭 = 기기와 같은 메뉴. 숨겨도 걸음·이벤트·부화는 계속(숨기면 홈 화면에 둠). 숨김 상태는 다음 실행에도 유지.
- **알림**(macOS 배너, 처음 실행 때 허용): 동료가 주워 온 것 · 알 부화 · 진화/레벨(5의 배수) · 날씨 변화 · 해금(새 코스·기기). 우클릭 → 알림에서 종류별로 끄기.

## 걸음 = 키 입력 + 클릭

Mac엔 만보기가 없으니 **키 누름·마우스 클릭 1회 = 1걸음**. 시스템 입력 카운터(`CGEventSource.counterForEventType`)를 읽기만 하므로 손쉬운 사용/입력 모니터링 권한이 필요 없고, 무엇을 입력했는지는 알 수 없음(횟수만). 같은 로그인 세션이면 앱을 꺼둔 동안의 입력도 다음 실행 때 합산.

20걸음 = 1W (최대 9999W). 자정에 오늘 걸음이 기록으로 넘어감(최근 7일).

## 조작 (◀ · ● · ▶ + 아래 ⌂ 홈, 또는 ← / return·space / → / esc)

- **화면 클릭**도 됨: 메뉴·카드·도구 화면은 왼쪽 1/3 = ◀, 가운데 = ●, 오른쪽 1/3 = ▶ / 레이더·다우징은 풀숲을 직접 클릭 / 배틀은 기술 이름 클릭 / 메시지는 클릭하면 넘어감. 그 외 빈 곳은 드래그.
- **홈**: ◀/▶ → 메뉴. ⌂(esc)는 어디서든 홈 — 배틀 중이면 도망. 메뉴 끝에서 한 번 더 넘기거나 20초 방치해도 홈.
- **포켓 레이더** (10W): 풀숲 4개 중 하나가 1.5초 뒤 흔들리며 `!` — 2초 안에 커서를 옮겨 가운데. 성공하면 배틀.
  - **연쇄**: 잡거나 쓰러뜨리면 레이더가 무료로 이어짐. 연쇄마다 `!` 시간이 짧아지고(최소 0.8초) 희귀한 A·B 칸 확률 +25%(4연쇄까지, 최대 90% — 흔한 포켓몬도 계속 섞임), 이로치 확률 1/128 → 1/(128÷(연쇄+1)). 놓치거나 도망·패배하면 끊김.
- **배틀**: 레벨이 상대보다 10 이상 높을수록 덜 빗나가고 덜 맞음(낮으면 반대). 무대엔 한 번에 한 마리만 원래 크기로(공격하는 쪽이 돌진 → 맞는 쪽이 흔들림·깜빡임, 급소는 화면 반전). 볼은 포물선으로 날아가 붉은 빛으로 빨아들이고, 2~3번 흔들린 뒤 딸깍(별) 또는 튀어나옴. 서로 HP 4. 공격(80% 명중, 1/8 급소 2뎀) / 피하기(상대 공격 회피, 가끔 도망감) / 볼(HP 4→20% … 1→80%, 실패 시 1/4 도망) / 도망. 쓰러뜨리면 못 잡음 — 약하게 만들어 잡기.
- **다우징** (3W): 풀숲 6개, 2번 기회. 빗나가면 `가깝다!`(옆 칸) / `멀다...`.
- **커넥트**: 워커의 포켓몬·도구를 상자/가방으로 보냄(워커는 각각 3개까지, 넘치면 바로 상자로).
- **트레이너 카드**: 코스·오늘/합계 걸음·일수·도감 / 최근 7일 그래프.
- **포켓몬 · 도구**: 워커에 들고 있는 것. 포켓몬 페이지에서 ● = **그 포켓몬과 함께 걷기**(원래 동료가 그 자리로).
- **상자**: 커넥트로 보낸 포켓몬을 한 마리씩. ● → 함께 걷기 / 놓아주기(확인 후, 레벨÷2 W 돌려받음) / 정렬(번호순 ↔ 레벨순) / 닫기.
- **도감**: 만난(봤음) · 잡은(잡음) 포켓몬만 넘겨봄. 번호·이름·타입, 본 것만이면 실루엣. 이로치로 잡은 적 있으면 일반/이로치 색이 2초씩 번갈아.


우클릭 = "게임 쪽": 코스 변경(누적 W로 해금 — 원작 수치, 이벤트 코스는 도감 수), 함께 걷기(종류 ▸ 개체 서브메뉴, 워커·상자의 포켓몬), 진화의 돌 쓰기, 교환소(진화의 돌·도구 1000W), 가방, 크기(×2/×3/×4), 기기 색(몬스터볼/슈퍼볼/하이퍼볼/마스터볼 + 도감 보상 프리미어볼/럭셔리볼), 화면(컬러/원작/백라이트), 종료. 코스를 바꾸면 커넥트 후 새로 페어링(코스 걸음 0부터). 동료 교체는 코스 걸음 유지(원작은 재페어링이라 초기화).

## 규칙 (원작)

- 코스마다 그룹 A/B/C 각 2마리, **그룹마다 1마리**가 풀숲에 있음 — 페어링 때, 그리고 **게임 속 하루(1,000걸음)마다** 다시 뽑힘(원작은 페어링 때만).
- 레이더 추첨: 희귀한 A부터 "코스 걸음 ≥ 필요 걸음 이고 확률 당첨"이면 그 포켓몬, 아니면 다음 → C는 보장. (Serebii 표의 퍼센트가 이 방식으로 정확히 재현됨: A 70 → B (1−.7)×75 = 22.5 → C 7.5)
- 도구도 같은 방식(희귀한 것부터, 상처약류가 보장).
- 함께 걷는 포켓몬이 코스의 특기 타입 3개 중 하나면 필요 걸음 25% 감소(4세대 타입 기준).
- **이로치**: 레이더에서 만난 포켓몬이 1/128 확률로 이로치(4세대 원작은 1/8192 — 여기선 하루 몇 판이라 너무 희박, `Walker.swift`의 `shinyOdds`). `✦ 반짝! ✦` + 배틀 중 반짝임, 목록엔 ★. 이로치 색은 HGSS 일반/이로치 스프라이트의 픽셀 대응으로 만든 종별 팔레트. 원작 포켓워커엔 없는 요소.
- 원작과 다른 점: 소리 없음, 이벤트 코스는 도감 수로 해금, 동료 교체 시 코스 걸음 유지.

## 홈 화면

- **동료 이벤트**: 150~400걸음마다 동료가 말풍선(♪ ♥ !)을 띄우고, 4번에 1번은 코스에서 도구를 주워 옴(원작 포켓워커의 이벤트처럼).
- **게임 속 시간 = 걸음**(실제 시계가 아님): **하루 = 1,000걸음**(0걸음 = 아침 6시), 새벽 4~6시 · 낮 · 저녁 17~20시 · 밤 20~4시(별, 땅도 어둡게). 흐리면 회색 하늘.
- **계절 = 게임 속 7일(7,000걸음)**: 봄(꽃) → 여름 → 가을(단풍·누런 들) → 겨울(눈 덮인 땅·흰 산봉우리), 배틀 발판 색도. 바뀌면 알림. 트레이너 카드에 "가을 2일째 · 밤".

## 도감 보상

- 잡은 종 수로 원작의 이벤트 코스 7개가 열림: 노란 숲 10 · 바다 건너편 20 · 밤하늘의 끝 30 · 랠리 45 · 쇼핑 60 · 챔피언의 길 80 · 우정의 초원 100 (원작은 GTS·배포 이벤트로 열던 코스).
- 기기 색: 프리미어볼 15종 · 럭셔리볼 50종. 달성하면 홈에서 알림.

## 알 · 전설 (원작엔 없음 — 코스에 없는 계열을 채우는 길)

- **알**: 동료 이벤트 중 약 8번에 1번(알이 없을 때) 알을 주워 옴. 코스에 안 나오는 계열의 기본형 111종(스타터·화석·미뇽·베이비 등, 아직 없는 종 우선). 원작 부화 걸음(부화 사이클 × 255)만큼 걸으면 Lv.1로 부화. 홈에 알 아이콘(곧 부화하면 흔들림), 트레이너 카드 3쪽에 남은 걸음.
- **껍질몬**: 토중몬이 아이스크로 진화할 때 함께 생김(원작처럼).
- **전설 코스 8개**(도감 수로 해금): 전설의 새 둥지 150 · 방황하는 들판 170 · 고대 유적 190 · 호연의 하늘과 바다 210 · 신오 호수 230 · 시공의 틈 260 · 환상의 숲 300 · 시작의 방 350. 코스의 일반 포켓몬·도구는 기존 코스와 같고, 레이더에서 **2%(+연쇄당 1%)** 로 아직 없는 전설이 나옴. Lv.50(아르세우스 80), 볼 효과 절반.
- 이걸로 **493종 전부** 얻을 수 있음(`tools/gen.py`가 생성할 때 검사).

## 날씨 (원작엔 없음)

- **1,000걸음마다** 무작위로 바뀜: 맑음 · 비 · 눈 · 안개. 코스 종류별 확률(해변·호수는 비, 산길은 눈 — 얼음 산길은 70% 눈, 동굴은 안개뿐).
- 계절이 날씨를 기울임: 겨울 눈 ↑, 여름 맑음 ↑(눈 ↓), 봄 비 ↑, 가을 안개 ↑.
- 날씨에 맞는 타입의 출현 확률 ×1.5(최대 90%) — 맑음 불꽃·풀 / 비 물·전기 / 눈 얼음 / 안개 고스트·에스퍼.
- 홈의 코스 그림·배틀 무대에 비·눈·안개가 내리고 흐린 날은 하늘이 회색. 바뀌면 홈에서 알림, 트레이너 카드에 현재 날씨.

## 레벨 · 진화

- **1걸음 = 경험치 1** (HGSS 포켓워커 원작 규칙). 종별 성장 곡선(4세대 경험치표), 경험치는 **포켓몬마다** 저장 → 동료를 바꿔도 각자 레벨 유지. 레벨 업은 홈 화면에서 알림.
- **진화**(4세대 방식을 워커에 맞춤, 데이터는 PokeAPI):
  - 레벨: 레벨 업 순간 조건(레벨·성별·게임 속 낮/밤·가방의 도구·상자에 특정 포켓몬) 충족 시. 기술을 배워야 하는 진화(에이팜·왕자리 등)는 그 기술을 배우는 레벨로.
  - 친밀도(피츄·이브이→에브이/블래키·골뱃 등)·아름다움(빈티나): 함께 **10,000걸음** 걸은 뒤 레벨 업.
  - 장소: 이브이→리피아(숲 코스)/글레이시아(얼음 산길), 레어코일·코코파스(동굴 코스).
  - 진화의 돌: 우클릭 → **진화의 돌 쓰기**. 돌·진화 도구는 우클릭 → **교환소**에서 1000W (HGSS에선 포켓슬론 포인트로 교환하던 것). 달의돌은 다우징으로도 나옴.
  - 통신교환: 그 포켓몬과 함께 걷는 중 **커넥트** = 통신 (필요한 도구는 가방에).
  - 진화는 되돌리거나 취소할 수 없음(B 캔슬 없음). 껍질몬(Shedinja)은 없음.

## 파일

| 파일 | 내용 |
|---|---|
| `Walker.swift` | 규칙 엔진 + 저장 상태 + 배틀 + 저장/복구 (`Foundation`만) |
| `main.swift` | AppKit UI: 기기, 96×64 4계조 LCD, 화면들, 메뉴 |
| `Data.swift` | **생성됨** — 493종 한국어 이름·타입·성장 곡선, 진화 250종, 35코스(일반 20 · 이벤트 7 · 전설 8), 알 풀 |
| `sprites.bin` | **생성됨** — 493종 × 2프레임 × 64×48, 2bpp 흑백 |
| `color.bin` | **생성됨** — 같은 도트의 컬러판, 종별 일반/이로치 15색 팔레트 + 4bpp |
| `fonts/` | Galmuri9·Galmuri7 (이민서, SIL OFL 1.1 — `fonts/OFL.md`). 닌텐도 DS 시스템 폰트를 본뜬 한글 도트 폰트, 원래 크기(10/8px)로만 써서 글자가 도트에 딱 맞음 |
| `tools/gen.py` | 위 둘을 원본(추출 스프라이트 시트, Serebii, PokeAPI)에서 재생성. Pillow 필요 |
| `Test.swift` | `PokeWalker --selftest` (105 checks) — 걸음/W/날짜/추첨 확률/배틀/레벨·진화/날씨/상자/저장/데이터 + 실제 뷰를 버튼·터치로 조작하는 흐름 검사(세이브는 건드리지 않음) |

세이브: `~/Library/Application Support/PokeWalker/state.json` (+ `.bak`, 손상 시 `state.corrupt-*.json`). 창 위치·크기·색은 `defaults dev.khmin.pokewalker`.

코스 한국어 이름은 번역(공식 한국판 명칭 아님). 스프라이트·데이터 저작권은 Nintendo / Game Freak / The Pokémon Company — 개인 소장용, 저장소는 비공개로.
