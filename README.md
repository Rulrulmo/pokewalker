# PokeWalker — 포켓워커 (HGSS, 2009) 데스크탑 펫

macOS 플로팅 포켓워커. 의존성 0, Swift 6 + AppKit, `swiftc`만 사용. 포켓몬 그림은 **HGSS 배틀 스프라이트**(80×80, 앞모습·뒷모습, 일반·이로치)를 한 픽셀 1pt로 LCD 도트 위에 그림 — 컬러 화면(기본)은 원래 색, 흑백 원작·백라이트 화면은 밝기로 4단계 회색. 코스·출현표·도구표는 원작 20개 코스 그대로.

```sh
./build.sh        # 빌드 + 셀프테스트 + PokeWalker.app 조립
./build.sh run    # 빌드 후 (재)실행 — 실행 중인 인스턴스를 죽임
open PokeWalker.app
```

### 다른 Mac에 주기

```sh
./build.sh dist   # dist/PokeWalker.zip — Apple Silicon + Intel, macOS 13 이상
```

zip을 보내면 받는 사람은 압축을 풀고 `PokeWalker.app`을 응용 프로그램 폴더로 옮긴 뒤:
1. 처음 한 번은 **우클릭 → 열기 → 열기** (Apple 개발자 서명이 없어서 더블클릭하면 "확인되지 않은 개발자" 경고로 막힘).
   macOS 15 이상에서 우클릭 열기도 막히면: 한 번 실행 시도 → **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**.
   또는 터미널: `xattr -dr com.apple.quarantine /Applications/PokeWalker.app`
2. 알림 허용 물어보면 허용.

경고 없이 더블클릭으로 열리게 하려면 Apple Developer Program(연 $99)의 Developer ID 서명 + 공증(notarization)이 필요. 세이브는 사람마다 따로(`~/Library/Application Support/PokeWalker`).

## 메뉴 막대 · 알림

- 상단 메뉴 막대에 몬스터볼 아이콘 + 현재 W(알이 곧 부화하면 `·알`). **클릭 = 워커 숨기기/보이기**, 우클릭 = 기기와 같은 메뉴. 숨겨도 걸음·이벤트·부화는 계속(숨기면 홈 화면에 둠). 메뉴 막대 아이콘이 안 보일 때(아이콘이 많거나 노치에 가려질 때, 시스템 설정 › 메뉴 막대에서 꺼졌을 때): **앱을 다시 열면**(Finder·Spotlight에서 PokeWalker 더블클릭) 워커가 다시 나오고, 실행할 때도 늘 보임.
- **알림**(macOS 배너): Apple 인증서로 서명되지 않은 앱은 macOS가 알림 권한을 묻지도 않고 거절해서(UNErrorDomain 1), 그 경우 `osascript`로 띄움 — 알림 센터에는 **"스크립트 편집기"** 이름으로 뜨고, 처음 한 번 허용이 필요할 수 있음. 우클릭 → 알림 → **테스트 알림 보내기**로 확인. 동료가 주워 온 것 · 알 부화 · 진화/레벨(5의 배수) · 날씨 변화 · 해금(새 코스·기기). 우클릭 → 알림에서 종류별로 끄기.

## 걸음 = 키 입력 + 클릭

Mac엔 만보기가 없으니 **키 누름·마우스 클릭 1회 = 1걸음**. 시스템 입력 카운터(`CGEventSource.counterForEventType`)를 읽기만 하므로 손쉬운 사용/입력 모니터링 권한이 필요 없고, 무엇을 입력했는지는 알 수 없음(횟수만). 같은 로그인 세션이면 앱을 꺼둔 동안의 입력도 다음 실행 때 합산.

20걸음 = 1W (최대 9999W). 자정에 오늘 걸음이 기록으로 넘어감(최근 7일).

## 생김새 · 조작 (◀ · ● · ▶ · ↩, 또는 ← / return·space / → / esc)

- **몬스터볼 카드**: 창 하나가 곧 몬스터볼 — 빨간 윗면에 **제목 줄**(LCD에 없는 것만: 홈은 코스·계절·날씨, 배틀은 코스 또는 타워 남은 수, 도감은 잡음·봤음)과 **LCD**(96×64 도트, 한 점 2pt = 1x 모니터에서도 딱 2픽셀), 가운데 검은 띠에 **◀ ● ▶ ↩**(●는 볼의 가운데 버튼), 흰 아랫면은 **패널 페이지** — 화면에 필요한 만큼만 아래로 늘어나고 위쪽은 제자리(대기 216×199pt, 배틀 311, 도감·상자 422; 화면 아래로 넘치면 잠깐 올라갔다가 짧은 화면이 되면 제자리로. 가장 긴 화면이 안 들어가는 크기는 메뉴에서 꺼짐). 크기 메뉴(보통 · 크게 · 아주 크게 = ×1 · ×1.5 · ×2, 포켓몬은 보통에서 1pt 한 픽셀). 홈에선 제목 줄 **⌄** 로 **상태**(동료 Lv·EXP·성격·특성·V, 오늘 걸음·W·누적, 알·타워·도감)를 펼치고 접음(기억함). 메뉴엔 2×5 **메뉴 타일**(클릭 = 고르기, 고른 걸 다시 클릭 = 열기), 배틀·도감·상자·상점엔 그 페이지. 윗면 색은 기기 색 테마를 따름.

- **화면 클릭**도 됨: 메뉴·카드·도구 화면은 왼쪽 1/3 = ◀, 가운데 = ●, 오른쪽 1/3 = ▶ / 레이더·다우징은 풀숲을 직접 클릭 / 배틀은 패널의 버튼 클릭(LCD는 드래그) / 메시지는 클릭하면 넘어감. 그 외 빈 곳은 드래그.
- **홈**: ◀/▶ → 메뉴. 메뉴 끝에서 한 번 더 넘기거나 20초 방치하면 홈.
- **↩ 뒤로**(esc): HGSS의 B처럼 **한 단계 위로** — 메뉴 페이지 → 홈, 도감 상세 → 도감 목록, 카드·가방·도감·상자·다우징·상점 목록 → 그 메뉴, 상점 수량·확인 → 목록, 배틀 기술·교체·도구 → 배틀 메뉴(들어온 칸). 대답이 필요한 화면에선 **커서만 '나가는 쪽'으로**(배틀 메뉴 → 도망/기권, 기술 배우기 → 배우지 않는다) 옮기고 ●로 정함. 되돌릴 수 없는 일은 한 번에 안 일어남: 레이더(낸 10W·연쇄 유지)·턴 연출·진화/부화 연출·교체 선택 중엔 무반응, 타워 로비에선 연승을 유지한 채 메뉴로. 타워 **기권**은 "기권할까?" 아니오/예(아니오가 기본).
- **포켓 레이더** (10W): 풀숲 4개 중 하나가 1.5초 뒤 흔들리며 `!` — 2초 안에 커서를 옮겨 가운데. 성공하면 배틀.
  - **연쇄**: 잡거나 쓰러뜨리면 **확률로** 레이더가 이어짐 — 85%에서 연쇄마다 8%p씩 내려가 최저 35%. 이어지면 무료, `!` 시간은 짧아지고(최소 0.8초):
    - 희귀한 A·B 칸 확률 +20%씩(8연쇄까지, 최대 90%), 이로치 1/128 → 128÷(1+연쇄×0.5) (3연쇄 1/51, 5연쇄 1/36, 10연쇄 이상 1/21)
    - 이어질 때마다 **+2×연쇄 W**, **5연쇄마다** 그 코스의 가장 희귀한 도구
    - 놓치거나 도망·패배하면 끊김. 최고 연쇄는 트레이너 카드(최근 7일 쪽)에.
- **배틀** (HGSS 싱글 배틀 규칙 — 더블·지닌 도구·폼만 빼고): 능력치 = 종족값·**개체값**(0~31)·**노력치**(쓰러뜨린 종의 노력치, 한 능력 255·합 510)·**성격**(±10%) 4세대 공식. 만나는 포켓몬마다 개체값·성격·**특성**(종의 1/2번 칸)·성별(종별 비율)을 뽑음(예전 포켓몬은 개체값 15·성격 노력). **nV** = 31인 개체값 수: 전설(코스·상점)은 3V 확정(6세대 이후 규칙), 포켓 레이더 연쇄 3·5·7·9에서 1·2·3·4V 확정(7세대 SOS 연쇄를 이 앱 연쇄 길이에 맞춤), 은색병뚜껑·금색병뚜껑으로 **대단한 특훈**(Lv.50부터, 배틀에서만 31로 — 개체값 자체와 잠재파워 타입은 그대로). 기술 467개(PokeAPI 기술 메타 + 4세대 수치로 롤백): 물리/특수 분리, **PP**, 명중·회피 랭크, 우선도, 급소 랭크, 자속·타입 상성, 날씨(코스의 비→비, 눈→싸라기눈, 안개 / 잔비·가뭄 등 특성), **상태이상**(독·맹독·화상·마비·잠듦·얼음) + 혼란·헤롱헤롱·풀죽음·씨뿌리기·저주·멸망의노래·앵콜·도발·트집·사슬묶기, 반사벽·빛의장막·신비의부적·흰안개·순풍, 압정·독압정·스텔스록, 대타출동·방어·버티기·교체 기술(유턴·바톤터치), 2턴 기술·반동·흡수·연속기·고정 데미지, 손가락흔들기·잠꼬대·따라하기 등, 특성 123개 대부분(위협·부유·틀깨기·트레이스·자연회복·정전기·가속 …). 더블 전용·지닌 도구 전용 기술(도우미·트릭·자연의은혜 등 12개)만 제외. 메뉴: 공격 / 볼(4세대 포획 공식 + 잠듦·얼음 ×2, 그 밖 상태이상 ×1.5) / 도구 / 도망(4세대 스피드 공식 — 실패할 수 있고 그림자밟기 등엔 못 도망). 고를 수 있는 기술이 없으면(PP 0·도발·트집·사슬묶기) 발버둥, 2턴 기술·난동 중엔 자동(그동안 도구·교체 불가). 도발 중 변화기·트집 중 같은 기술은 메뉴에서 막힘. 그림자밟기·개미지옥·자력·검은눈빛·조이기·뿌리박기에 걸리면 교체·도망 불가. 데미지는 4세대 공식 그대로(난수 85~100%, 단계마다 버림 — Bulbapedia 예시 168~196과 일치). 이기면 **경험치**(기초경험치 × 상대 레벨 ÷ 7, 트레이너 1.5배 — 그 상대와 싸운 포켓몬끼리 나눔)와 노력치(싸운 포켓몬 모두 전부). HP·PP·상태이상은 배틀마다 새로(워커엔 포켓몬센터가 없어서). 야생은 기술을 무작위로(원작처럼), 타워 트레이너는 센 기술 위주 + 상성이 나쁘면(내 기술에 약점 찔리고 자기 기술은 안 먹힐 때) 버티는 동료로 교체. 내 포켓몬이 쓰러지면 다음에 낼 포켓몬을 고름. 무대는 DS 배틀처럼 상대 앞모습이 오른쪽 위, 내 포켓몬 뒷모습이 왼쪽 아래(공격하는 쪽 돌진 → 맞는 쪽 흔들림, 쓰러지면 발판 아래로 가라앉음, 볼은 내 쪽에서 상대에게, 급소 화면 반전), HUD에 상태이상 표시.
- **새 기술**: 레벨 업(걸음·배틀·이상한사탕)이나 진화로 배울 기술이 생기면 홈에서 — 기술이 4개 미만이면 바로 배우고, 4개면 **잊을 기술 선택** 화면(◀ ▶로 고르고 ●, 5번째 = 배우지 않는다).
- **배틀**: HP 상자는 HGSS처럼 **LCD 위**에 — 상대는 왼쪽 위(잡은 적 있으면 몬스터볼 표시, 이름·Lv·**타입**(배틀 중 바뀐 타입 그대로 — 변색·텍스처·변신·포캐스트)·상태이상·HP 바), 내 쪽은 오른쪽 아래(HP 숫자까지). 기술이 날아가거나 볼을 던질 땐 흐려짐. 패널엔 메시지와 큰 버튼(공격 / 볼·도구·도망, 기술: 타입 색·PP·▲▼×(지금 상대 타입·특성 기준, 잠재파워·웨더볼은 실제 타입), 교체: 파티 HP, 도구, 예/아니오) — 고른 게 빨강. 클릭해도, 기기 버튼·키보드로 해도 됨. 배틀 내내 패널 높이는 그대로.
- **다우징** (3W): 풀숲 6개, 2번 기회. 빗나가면 `가깝다!`(옆 칸) / `멀다...`.
- **커넥트**: 워커의 포켓몬·도구를 상자/가방으로 보냄(워커는 각각 3개까지, 넘치면 바로 상자로).
- **트레이너 카드**: 코스·오늘/합계 걸음·일수·도감 / 최근 7일 그래프.
- **포켓몬 · 도구**: 워커에 들고 있는 것. 포켓몬 페이지에서 ● = **그 포켓몬과 함께 걷기**(원래 동료가 그 자리로).
- **상자**: 패널이 HGSS PC 박스처럼 **아이콘 격자**(한 페이지 6×5 = 30마리, ★ 이로치, ◆ 3V 이상)가 됨. 탭 **번호순 / 레벨순 / V순 / 최근**(보는 순서만 바뀜 — 상자 속 순서는 들어온 순서 그대로, 함께 걷기로 바꾼 동료는 맨 뒤 = 최근 첫 칸). 칸 클릭 = 고르기(LCD에 크게 · 레벨 · 성별 · V), 고른 걸 다시 클릭 또는 ● → **그 포켓몬의 페이지**: **성격**(올리고 내리는 능력치와 그 뜻, 무보정은 "변화 없음"), **특성**(무엇을 하는지 — 한국어판 설명, 뒤 세대에 바뀐 효과는 4세대 싱글 배틀 기준으로 고쳐 씀), **개체값·노력치 육각형**(HP 위, 시계 방향 공격·방어·스피드·특방·특공; 성격이 올리는 능력은 빨강·내리는 능력은 파랑, 대단한 특훈은 금색 31, 노력치 합), 아래 **함께 걷기 / 놓아주기**(확인: 아니오 / 예, 레벨÷2 W). 그 페이지에서 ● → LCD의 함께 / 놓아주기 / 닫기. ◀ ▶ 한 칸(페이지에서도), ↑ ↓ 한 줄, PageUp/Down·휠·패널 ◀ ▶ 한 페이지, ↩ 페이지 → 격자 → 메뉴.
- **도감**: 패널이 **아이콘 격자**(HGSS 박스 아이콘, 한 페이지 6×5 = 30종, 1번부터 493번까지 17페이지)가 됨 — 잡음은 컬러, 봤음은 옅은 실루엣, 못 본 종은 번호만. 탭 **전체 / 잡음 / 못 잡음**(봤지만 아직 못 잡은 종) **/ 이 코스**(지금 코스에 나오는 종, 전설 포함). 칸 클릭 = 고르기(LCD에 번호·이름·타입·그림), 고른 걸 다시 클릭 또는 ● → **상세 페이지**: 종족값 막대, **만나는 곳**(코스 원작/추가/손님/전설, 🔒 아직 안 열린 코스, 알, 무엇에서 진화), **진화**(대상 · 방법). 이동은 상자와 같음. 이로치로 잡은 적 있으면 격자에 ★, LCD에선 일반/이로치 색이 2초씩 번갈아.


기기 화면 글씨: 기본은 **매끈한 시스템 폰트**를 LCD 위에 그림(코스 그림·아이콘은 도트, 포켓몬은 스프라이트 그대로). 우클릭 → **화면 글씨 → 도트**로 원작처럼 전부 도트 글씨.

우클릭 = "게임 쪽": 코스 변경(누적 W로 해금 — 원작 수치, 이벤트 코스는 도감 수), 함께 걷기(종류 ▸ 개체, 종이 많아지면 최근 5마리 · ★ 이로치 · 도감 번호 50단위 묶음; 개체마다 레벨·성별·**성격·특성**(마우스를 올리면 기술·능력치·개체값·노력치), 맨 위엔 지금 동료의 성격·특성·기술·능력치·개체값·노력치; **1V부터 V 수 표시, 3V 이상은 호박색 굵게**(종 줄에 "최고 3V", 종이 많을 땐 "3V 이상" 목록도), 같은 레벨·성별·성격·특성·V 수는 "×n" 한 줄, 10줄 넘으면 "그 밖" 레벨 구간, 종마다 **중복 놓아주기**(이로치와 3V 이상은 모두 남기고, 그 밖엔 V 수 → 경험치 순 최고 1마리만. 확인 창에 남는 포켓몬 표시)), 진화의 돌 쓰기, 가방, 크기(보통/크게/아주 크게), 기기 색(몬스터볼/슈퍼볼/하이퍼볼/마스터볼 + 도감 보상 프리미어볼/럭셔리볼), 화면(컬러/원작/백라이트), 종료. 코스를 바꾸면 커넥트 후 새로 페어링(코스 걸음 0부터). 동료 교체는 코스 걸음 유지(원작은 재페어링이라 초기화).

## 규칙 (원작)

- 코스마다 그룹 A/B/C 각 4마리 — 원작 2마리 **+ 2마리(추가, 서식지·포획률 기준, 코스 레벨에 맞는 진화 단계)**. 추가분은 그 그룹의 필요 걸음·확률을 따름.
- 레이더 추첨: 10%는 **서식지 손님**(아래). 나머지는 원작처럼 희귀한 A 그룹부터 — "걸음 조건을 채운 후보가 있고 rand(100) < 그 후보들의 평균 확률"이면 그 그룹 — 그다음 **그룹 안에서 조건을 채운 후보 중 무작위**(날씨 타입 ×1.5 가중). C는 보장. (원작은 페어링 때 그룹마다 1마리만 실음 — 여기선 매번 4마리 중에서. Serebii 밴드는 그룹 단위로 그대로: A 70 → B (1−.7)×75 = 22.5 → C 7.5)
- **서식지 손님**(원작엔 없음): 코스마다 5종, 레이더 발견의 10%. 코스 하나에서 최대 17종이 매번 섞여 나옴.
- 도구도 같은 방식(희귀한 것부터, 상처약류가 보장).
- 함께 걷는 포켓몬이 코스의 특기 타입 3개 중 하나면 필요 걸음 25% 감소(4세대 타입 기준).
- **이로치**: 레이더에서 만난 포켓몬이 1/128 확률로 이로치(4세대 원작은 1/8192 — 여기선 하루 몇 판이라 너무 희박, `Sources/Model/Mon.swift`의 `shinyOdds`). `✦ 반짝! ✦` + 배틀 중 반짝임, 목록엔 ★. 이로치 색은 HGSS 일반/이로치 스프라이트의 픽셀 대응으로 만든 종별 팔레트. 원작 포켓워커엔 없는 요소.
- 원작과 다른 점: 소리 없음, 이벤트 코스는 도감 수로 해금, 동료 교체 시 코스 걸음 유지.

## 배틀 타워 · 상점

- **배틀 타워**(메뉴 끝): 참가비 50W, **3마리 파티**(동료 + 워커·상자에서 가장 강한 2마리) vs 트레이너의 3마리. 상대 레벨 = 파티 평균 + 연승÷3 (+0~2), Lv.30부터 최종 진화형. 메뉴: 공격 / 도구 / **교체** / 기권. 이길 때마다 **BP** 1(7연승마다 +3, 7연승 뒤엔 2씩), 배틀 사이에 HP 회복, 지면 연승 끝(최고 기록 보관). 경험치는 싸운 포켓몬에게.
- **상점**·**BP 교환소**(워커 메뉴, 배틀 타워 앞): ◀ ▶로 고르고 ● → **몇 개 살지**(◀ ▶ ±1, 키보드 ↑ ↓ ±10, 가진 돈만큼·최대 99개) → ● 구매, ↩ 목록으로. 패널에 목록(6줄, 효과·보유 수)과 − n개 + · 사기 버튼(클릭·스크롤). 한 번만 사는 것은 아니오 / 예. 더블클릭·키 누르고 있기로는 사지 않음.
- **상점**(W): 상처약류 · 회복약 · 기력의조각 · 슈퍼볼 · 하이퍼볼 · 상태이상 약 · PP에이드 · 배틀 강화 도구 · 영양제 · 노력치 내리는 열매 · 순백떡, 그리고 **지금 동료의 진화 도구 1000W**(HGSS에선 포켓슬론 포인트로 교환하던 것).
- **BP 교환소**: 하이퍼볼 2 · 고급상처약 3 · 풀회복약 5 · 회복약 6 · 부활초 6 · PP에이더 4 · PP맥스 8 · 이상한사탕 8 · 영양제 1 · 은색병뚜껑 25 · 금색병뚜껑 120 · 기기 색 "배틀 골드" 40.
- **전설 구매**(각 1번, "정말 살까?" 예/아니오 — 아니오가 기본, **여기서만** 얻음 — 전설 코스·타워에는 안 나옴): 상점에서 **칠색조 Lv.50 — 9,999W**(W 최대치 전부), BP 교환소에서 **뮤츠 Lv.70 — 300BP**(타워 약 30세트).

## 홈 화면

- **동료 이벤트**: 150~400걸음마다 동료가 말풍선(♪ ♥ !)을 띄우고, 4번에 1번은 코스에서 도구를 주워 옴(원작 포켓워커의 이벤트처럼).
- **게임 속 시간 = 걸음**(실제 시계가 아님): **하루 = 1,000걸음**(0걸음 = 아침 6시), 새벽 4~6시 · 낮 · 저녁 17~20시 · 밤 20~4시(별, 땅도 어둡게). 흐리면 회색 하늘.
- **계절 = 게임 속 7일(7,000걸음)**: 봄(꽃) → 여름 → 가을(단풍·누런 들) → 겨울(눈 덮인 땅·흰 산봉우리), 배틀 발판 색도. 바뀌면 알림. 트레이너 카드에 "가을 2일째 · 밤".

## 도감 보상

- 잡은 종 수로 원작의 이벤트 코스 7개가 열림: 노란 숲 10 · 바다 건너편 20 · 밤하늘의 끝 30 · 랠리 45 · 쇼핑 60 · 챔피언의 길 80 · 우정의 초원 100 (원작은 GTS·배포 이벤트로 열던 코스).
- 기기 색: 프리미어볼 15종 · 럭셔리볼 50종. 달성하면 홈에서 알림.

## 알 · 전설 (원작엔 없음 — 코스에 없는 계열을 채우는 길)

- **알**: 동료 이벤트 중 약 8번에 1번(알이 없을 때) 알을 주워 옴. 코스에 안 나오는 계열의 기본형 111종(스타터·화석·미뇽·베이비 등, 아직 없는 종 우선). 원작 부화 걸음(부화 사이클 × 255)만큼 걸으면 Lv.1로 부화. 홈에 알 아이콘(곧 부화하면 흔들림), 트레이너 카드 3쪽에 남은 걸음.
- **껍질몬**: 토중몬이 아이스크로 진화할 때 함께 생김(원작처럼).
- **전설 코스 8개**(도감 수로 해금): 전설의 새 둥지 150 · 방황하는 들판 170 · 고대 유적 190 · 호연의 하늘과 바다 210 · 신오 호수 230 · 시공의 틈 260 · 환상의 숲 300 · 시작의 방 350. (칠색조·뮤츠는 코스에 없음 — 구매 전용) 코스의 일반 포켓몬·도구는 기존 코스와 같고, 레이더에서 **2%(+연쇄당 1%)** 로 아직 없는 전설이 나옴. Lv.50(아르세우스 80), 볼 효과 절반.
- 이걸로 **493종 전부** 얻을 수 있음(`tools/gen.py`가 생성할 때 검사).

## 날씨 (원작엔 없음)

- **1,000걸음마다** 무작위로 바뀜: 맑음 · 비 · 눈 · 안개. 코스 종류별 확률(해변·호수는 비, 산길은 눈 — 얼음 산길은 70% 눈, 동굴은 안개뿐).
- 계절이 날씨를 기울임: 겨울 눈 ↑, 여름 맑음 ↑(눈 ↓), 봄 비 ↑, 가을 안개 ↑.
- 날씨에 맞는 타입의 출현 확률 ×1.5(최대 90%) — 맑음 불꽃·풀 / 비 물·전기 / 눈 얼음 / 안개 고스트·에스퍼.
- 홈의 코스 그림·배틀 무대에 비·눈·안개가 내리고 흐린 날은 하늘이 회색. 바뀌면 홈에서 알림, 트레이너 카드에 현재 날씨.

## 레벨 · 진화

- **1걸음 = 경험치 1** (HGSS 포켓워커 원작 규칙). 종별 성장 곡선(4세대 경험치표), 경험치는 **포켓몬마다** 저장 → 동료를 바꿔도 각자 레벨 유지. 레벨 업은 홈 화면에서 알림.
- **진화**(4세대 방식을 워커에 맞춤, 데이터는 PokeAPI):
  - 레벨: 레벨 업 순간 조건(레벨·성별·게임 속 낮/밤·가방의 도구·상자에 특정 포켓몬) 충족 시. 기술을 배워야 하는 진화(에이팜·왕자리 등)는 그 기술을 배우는 레벨로.
  - 친밀도(피츄·이브이→에브이/블래키·골뱃 등)·아름다움(빈티나): 함께 **10,000걸음** 걸은 뒤 레벨 업.
  - 장소: 이브이→리피아(숲 코스)/글레이시아(얼음 산길), 레어코일·코코파스(동굴 코스).
  - 진화의 돌: 우클릭 → **진화의 돌 쓰기**. 돌·진화 도구는 워커 메뉴 → **상점**에서 1000W (HGSS에선 포켓슬론 포인트로 교환하던 것). 달의돌은 다우징으로도 나옴.
  - 통신교환: 그 포켓몬과 함께 걷는 중 **커넥트** = 통신 (필요한 도구는 가방에).
  - 진화는 되돌리거나 취소할 수 없음(B 캔슬 없음). 껍질몬(Shedinja)은 없음.
