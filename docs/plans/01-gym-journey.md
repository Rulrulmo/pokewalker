# 01 · 체육관 여정 — 성도 8 → 포켓몬리그 → 관동 8 → 은빛산 레드

> 상태: 초안 (검토 전) · 의존: 없음. 02 로켓단 이야기가 `state.badgeCount` 하나를, 06 업적이 배지 칸 격자를 가져다 씀. 메뉴 타일 · 보상 · 배틀 종류 같은 공통 시스템은 → README.md 참고.
> 팀 데이터는 **pret/pokeheartgold의 실제 HGSS 트레이너 표**(`trainers.json`)를 그대로 씀. 걸음 수 가정은 02와 같게 **하루 1만 타(=500W)**.

## 1. 한 줄 요약 · 왜 재미있나

**키보드를 칠수록 동료가 크고, 누적 W가 쌓이면 다음 체육관 문이 열린다. 관장 16명, 사천왕, 목호, 그리고 두 달 뒤 은빛산의 레드.**

- 지금 이 앱엔 "끝"이 없음: 레이더·타워는 무한 반복이고, 코스 해금(누적 W)과 도감이 유일한 이정표. 체육관은 **정해진 순서와 정해진 상대가 있는 줄거리**를 줌 — "오늘은 꼭두의 밀탱크를 넘자" 같은 목표.
- 데스크 펫에 맞는 점: 배틀 한 판(2~6마리)이 **1~4분**이고 원할 때만 함. 문이 열리면 알림 한 번, 메뉴 타일 한 칸, 로비 한 화면. 안 해도 불이익 없음.
- 레벨은 **원작 그대로 고정**이라, 해금 페이스(누적 W)와 동료의 레벨(1걸음 = 경험치 1)이 같은 시계로 감: 문이 열릴 때쯤이면 동료가 딱 그 관장의 에이스 레벨 근처.

## 3. 플레이 흐름

1. **문이 열림**: 누적 W가 문턱을 넘고 앞 배지가 있으면 홈에서 `.say(["도라지시티 체육관이", "문을 열었다!"])` + 알림(기존 종류 `unlock`). 홈 상태 시트에 `체육관  배지 3 · 다음 꼭두 (Lv.19)` 한 줄(02 이야기의 홈 배너와는 다른 자리 — → README.md '홈 알림 자리').
2. **메뉴/홈 키 → 메뉴 타일 "체육관"**(노트 `배지 3/16`). 새 타일 — 01 · 03 · 04 · 05 · 07이 한 칸씩 써서 2×7(→ README.md '메뉴 타일').
3. **로비**(`Screen.gym`): 패널 탭 `성도 / 관동 / 리그`, 2열 × 4줄 칸(배지 그림 + 마을·관장 + 에이스 Lv / ✓ / 🔒 조건). LCD는 고른 체육관: 타입 색 바닥 + 관장 그림(못 이긴 관장은 타워 로비처럼 **실루엣**, 이기면 컬러) + 이름·타입·에이스 Lv. 아래 **파티 6칸**과 `도전` · `나가기`.
4. **● 도전** → 인트로: `.say`로 관장 그림 + 한마디(2줄) → 기존 트레이너 인트로 그대로(걸어 나와 "체육관 관장 꼭두가 승부를 걸어왔다!" → 볼 던지고 퇴장).
5. **배틀**: 지금 타워 배틀과 같음(공격 / 도구 / 교체 / 기권, 트레이너 AI·교체 AI). 마지막 한 마리가 나오면 원작 `LAST_POKE` 대사 한 줄.
6. **이김**: 관장이 다시 나와 `LOSE` 대사 → **배지 연출**(LCD 가운데 배지 32×32가 반짝이며 커짐, "레귤러배지를 받았다!") → `기술머신45 헤롱헤롱` → 동료가 배울 수 있으면 기존 **기술 배우기 화면** → 홈.
7. **짐**: "눈앞이 캄캄해졌다…" → 홈. 페널티 없음, 바로 다시 도전 가능.
8. **리그 탭**: 일목 → 독수 → 시바 → 카렌 → 목호 진행 점 5개. 한 판 이기면 로비로(나가도 진행 유지), 지면 일목부터. 목호를 이기면 **전당 등록**(LCD에 파티가 한 마리씩 HGSS 등장 모션, 패널에 날짜·걸음) → 관동 탭이 열림.
9. **16개 뒤**: 리그 2회차, 재대결 전화, 은빛산 레드가 열림(관동 탭 맨 끝 칸 "은빛산").

**보상**
- 첫 승: 배지 + **에이스 Lv × 10W**(비상 130W … 레드 880W, 합계 약 9,700W — W 최대 9,999는 그대로) + 기술머신. W는 `watts`에만 더함 — `earned`에 더하면 다음 체육관 문턱이 당겨짐(→ README.md '보상 · 해금 층').
- 기술머신: 동료가 배울 수 있으면(PokeAPI `pokemon_moves.csv`, HGSS 판 기술머신 방법) `learning` 줄에 넣어 기존 기술 배우기 화면. 못 배우면 가방에 "기술머신45"로(지금처럼 팔기 100W).
- 챔피언 첫 승: 전당 등록 + **학습장치**(열린 질문 7: 워커의 3마리도 걸음 경험치 50%).
- 레드 첫 승: 기기 색 **"GS볼"**(금·은 윗면) — 도감 보상 기기 색과 같은 줄.
- 재대결: 관장 1명 **5BP**, 리그 2회차 완주 **20BP**, 레드 **20BP**. 타워(한 판 1BP, 7연승마다 +3)보다 한 판당 후함 — 대신 게임 속 한 주(7,000걸음)에 한 번.

**재대결 전화**(16개 뒤): 게임 속 요일 = `gameDay % 7`(0 = 월), 시간대 = HGSS 아침 4–10 · 낮 10–20 · 밤 20–4(`hour`). 관장마다 원작 전화 시간(Serebii `gym-rematch.shtml`: 비상 토요일 아침, 호일 목요일 낮, 유빈 화요일 밤, 이향 금요일 밤 …)이 되면 알림 `"비상에게서 전화가 왔다!"` → 그 게임 하루(1,000걸음) 동안 로비 칸에 📞. 하루 1만 타면 게임 속 한 주가 현실 0.7일 — 관장마다 하루 한두 번 전화.
재대결 팀 = pret #712~727(Lv.48~62, 그린 67~72), 사천왕 2회차 #702~705 + 목호 #701(Lv.58~75).

**파티** = 동료 + **워커의 3마리**(사용자가 포켓몬 화면의 "워커로 / 상자로"로 고름) + 상자에서 경험치 높은 순으로 채워 최대 6. 타워는 지금처럼 3.

## 6. 데이터 · 저장

**생성 데이터**(`tools/gen.py` → `Data.swift`):

```swift
struct Leader { let key: String; let name, place, type: String; let badge: Int?; let tm: (no: Int, move: Int)?
                let sprite: String; let iv: Int; let mons: [(dex: Int, level: Int, moves: [Int])]; let lines: [String] }  // lines: 인사 · 마지막 한 마리 · 졌을 때
let leaders: [Leader]   // 성도 8 · 리그 5 · 관동 8 · 레드 · 재대결 16 · 리그 2회차 5 (key: "falkner", "falkner.2", "will.2" …)
```
- gen.py가 pret JSON의 번호로 뽑고, `SPECIES_MR_MIME` → PokeAPI `mr-mime`, `MOVE_SAND_ATTACK` → `sand-attack`로 도감·기술 번호를 맞춤(못 맞추면 생성 실패).
- 한국어(관장·마을·배지 이름, 대사)는 gen.py 안의 손 표. pret은 영어뿐이라 대사는 **직접 옮긴 짧은 문장**.
- 개체: `Mon(dex:level:female:)` + `known = moves`, `ivs = [iv]×6`, 성격·특성·성별은 `key`의 **FNV 해시 시드**(Swift `hashValue`는 실행마다 달라서 못 씀).

**세이브**(`Walk`, 전부 Optional — 옛 세이브는 키가 없으면 nil로 그대로 열림):

```swift
var beaten: [String]? = nil          // 한 번이라도 이긴 leader key, 정렬 ("falkner", "lance", "red", "falkner.2" …) — 배지는 여기서 계산
var league: Int? = nil               // 리그 연전의 다음 상대 0-4 (nil = 연전 중 아님); 2회차도 같은 칸
var rematchDay: [String: Int]? = nil // 재대결 이긴 gameDay (게임 속 한 주에 한 번)
var call: String? = nil, callDay: Int? = nil   // 지금 온 전화와 그 게임 하루
var fame: [Fame]? = nil              // 전당 등록 (Fame: days, total, team: [Mon])
var badgeCount: Int { leaders.prefix(16).filter { (beaten ?? []).contains($0.key) }.count }   // 02가 읽는 값
```
배틀 중 상태는 저장 안 함(타워와 같음) — 배틀 도중 앱을 끄면 그 판만 없던 일, 리그 진행(`league`)은 남음.

## 8. 멀티 확장 여지

- **친구 체육관**: 내 파티(`[Mon]`, 이미 Codable) + 이름 + 트레이너 그림 하나를 `Leader`와 같은 모양의 JSON → base64 한 줄 "체육관 코드"로. 친구가 붙여 넣으면 로비에 "친구" 탭이 생기고 같은 엔진으로 싸움. 이기면 `beaten`에 `"friend:<코드 해시>"`.
- **검증 가능한 결과**: `Battle`은 시드(`seed`) + 입력만으로 똑같이 재생됨(단 지금은 `turn`마다 뷰의 `rng`에서 새 시드를 받음 → 03의 `fightRng` 분리가 먼저, → 03-raid.md §5). 입력 목록(턴마다 `Move`)을 남기면 서버가 같은 엔진으로 다시 돌려 확인 가능 — `Sources/Model`·`Sources/Battle`은 Foundation만 써서 리눅스 Swift 서버에서도 돎.
- **작은 서버**: 코드 올리기/받기(친구 코드 = 짧은 ID), 전당 등록 공유, "배지 16개까지 걸린 누적 걸음" 순위.
- **지금 해 둘 것**(비용 거의 0): 관장을 코드가 아닌 **데이터**(`Leader`)로 · 기록을 **문자열 키**로(`beaten`) · 그림을 **이름**으로(`sprite`) · 체육관 배틀 시드를 `Battle.seed`로 명시. 서버·코드 공유 자체는 만들지 않음.

## 10. 리스크 · 열린 질문

**리스크**
- **파티 격차**: 걸음 경험치는 동료만 받아서, 레드(Lv.80~88 여섯)는 동료 하나만 강해선 못 이김. 동료를 번갈아 키우면 한 마리당 걸음이 나뉨(60일 60만 걸음 ÷ 6 = 각 Lv.46). → 학습장치(질문 7) + 트레이너 경험치 ×1.5(리그 목호 망나뇽 Lv.50 한 마리 ≈ 2,900) + BP 이상한사탕으로 메움. 레드는 "두세 달 목표"로 받아들이는 게 맞음.
- **이미 누적 W가 많은 세이브**: 문턱은 다 넘었을 것 → 배지 순서 조건만으로 하나씩 열림. 동료 레벨이 높으면 초반 8개는 연승 — 온보딩으로 괜찮음.
- **지닌 도구 없음**: 원작보다 쉬움(특히 레드 피카츄 전기구슬). 레벨로 보정하진 않음.
- **대사 번역**: 공식 한국판 문장이 아님 → README에 "번역"이라고 적음(코스 이름처럼).
- **메뉴 자리**: 다른 기획(03 · 04 · 05 · 07)과 합치면 타일 13개(2×7) — 패널이 세 줄(105pt) 길어짐(→ README.md '메뉴 타일').

**열린 질문** (→ 추천 기본값)
1. 메뉴 자리: 새 타일 "체육관" vs 배틀 타워 타일 안의 탭? → **새 타일**(자리는 README.md '메뉴 타일').
2. 레벨: 원작 고정 vs 타워처럼 파티 맞춤? → **원작 고정**(첫 대결·재대결 모두 원작 값).
3. 내 파티 크기: 6(원작) vs 3(타워와 같게)? → **6** = 동료 + 워커 3 + 상자 상위 2.
4. 도전료·패배 페널티? → **둘 다 없음**. 재대결도 무료, 보상은 BP.
5. 리그: 연전 사이 HP 회복 · 지면 일목부터? → **예, 예**(나갔다 와도 진행 유지).
6. 배지 효과: 표대로 작은 보너스 vs 모으기만(4세대처럼)? → **표대로**(성도만, 한 줄씩).
7. 학습장치(워커의 3마리 걸음 경험치 50%)를 챔피언 보상으로? → **넣음**. 없으면 레드가 훨씬 멀어짐(파티 격차 참고).
8. 상대가 가방 도구(풀회복약 등)를 원작 수량대로 씀? → **3단계에서 넣음**(체감 난이도는 원작 쪽).
9. 대사: 직접 옮긴 짧은 한국어 vs 대사 없이 이름만? → **짧은 번역**(인사·마지막 한 마리·졌을 때 3줄).
10. 라이벌 실버(그림 200 확인됨)? → **안 넣음**. 넣는다면 팀은 파티 맞춤 + 스타터 대신 동료 상성.
11. 재대결 창: 게임 속 요일·시간(원작 느낌, 알림) vs 언제나 + 한 주 쿨다운? → **게임 속 요일·시간**.
12. 레드 보상 기기 색 "GS볼"? → **예**(한 번만, `bought`에 이름 — 타워 "배틀 골드"와 같은 검사, → README.md '선물 기기 색').
