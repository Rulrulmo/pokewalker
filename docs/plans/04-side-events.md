## 1. 한 줄 요약 · 왜 재미있나

| 모듈 | 한 줄 | 데스크 펫에 맞는 이유 |
|---|---|---|
| **벌레잡기 대회** | 화·목·토에만 열리는 20분짜리 대회. 컴퍼티션볼 20개로 벌레 포켓몬 한 마리를 골라 잡고, HGSS 공식대로 점수를 매겨 NPC 5명과 순위를 겨룸 | "오늘은 대회 날"이라는 **요일 리듬**. 20분 동안 일하다가 가끔 보면서 풀숲을 뒤짐. 판마다 **HP를 깎을까, 가득 찬 채로 던질까**를 고민하게 됨 |
| **사파리존** | 배틀 없이 볼 · 먹이 · 진흙만으로 잡기. 입장하면 **일하는 동안 포켓몬이 알아서 나타나고** 볼 30개를 다 쓸 때까지 이어짐 | 누르지 않아도 흘러가는 **수동형**. 나타난 포켓몬은 잠깐 기다려 주니까 짬 날 때 한 번만 누르면 됨 |
| **포켓슬론** | 10~30초짜리 반응 · 연타 · 리듬 미니게임. 슬론 포인트를 모아 **요일마다 바뀌는 상품**(진화의 돌 등)과 교환 | 짧게 한 판 하기 좋음. **릴레이 런**은 평소처럼 타이핑만 하면 되는 경기(워커가 입력 **횟수**만 셈) |

세 모듈의 결이 다르다. 대회는 **시간 제한 + 선택**, 사파리는 **기다리면 오는 것**, 포켓슬론은 **손기술**.

## 3. 플레이 흐름

### 3-0. 들어가는 곳 (셋 공통)
- 메뉴에 타일 **"나들이"** 하나(노트: `오늘 대회!` / `사파리 볼 23` / `슬론 1,240P`). 누르면 패널에 로비 3줄 — 벌레잡기 대회 · 사파리존 · 포켓슬론. 해금 전 줄은 조건만 보여 줌(`누적 2,000W`).
- 대회 · 사파리를 하는 동안엔 **홈 LCD가 그 장소**(자연공원 / 사파리 구역 그림)로 바뀌고, 메뉴/홈 키로 드나들어도 계속됨(타워 로비의 "연승 유지"와 같은 방식). 우클릭 메뉴에 `나들이 ▸ 대회 그만두기 / 사파리 나가기`.
- 알림 종류 `("event", "나들이 (대회 날 · 사파리)")` 추가. 기본으로는 **대회 날 첫 실행 때 한 번만** 알림. 사파리에 포켓몬이 나타나면 배너 대신 메뉴 막대 W 옆에 `·!`(지금 `·알`이 쓰는 자리).

### 3-1. 벌레잡기 대회 (화·목·토)
1. 대회 날 홈 → `.say(["오늘은", "벌레잡기 대회 날!"])`. 나들이 → 벌레잡기 대회 → 패널 `참가 · 무료`. 이미 오늘 나갔으면 `오늘 결과: 2위 (312점)`.
2. 참가하면 홈 LCD = 자연공원. 위쪽 줄에 `⏱ 18:40 · 볼 20`, 아래쪽엔 지금 판정 대상(`스라크 Lv.13 · HP 72%`, 없으면 `아직 없음`).
3. **패널 = 레이더와 같은 풀숲 4개**(`drawRadar` 재사용, 공짜). 한 번 찾고 나면 30걸음을 더 걸어야 다음 찾기(패널에 `다음까지 12걸음`). 맞히면 배틀 — 메뉴 **공격 / 볼(컴퍼티션볼 ×1.5, 남은 수) / 도망**(도구 없음).
4. 잡았을 때 이미 한 마리가 있으면 `LCD: 새로 잡은 것 · 패널: 지금 것과 새것(Lv · HP% · V) · [바꾼다] [그대로]`(기본값 = 그대로). 놓친 쪽은 풀어 줌(도감엔 "잡음"으로 남음 — 원작과 같음).
5. 20분이 지나거나 볼을 다 쓰거나 `그만두고 심사`를 누르면 **심사 연출**: 분수 앞, 3위 → 2위 → 1위 순서로 트레이너 그림 + 포켓몬 + 점수(`.say` 줄줄이). 상품은 가방으로, 판정 포켓몬은 워커로(`keep`).

```
┌ LCD 96×64 ───────────────────────┐   ┌ 패널 ───────────────────────────┐
│ 벌레잡기 대회     ⏱18:40 ◓×17   │   │ 풀숲을 골라요 · 다음까지 0걸음    │
│  (자연공원 그림: 풀숲 · 분수)      │   │ ┌─────────┐ ┌─────────┐          │
│      ,,,  동료(걷기) ,,, !        │   │ │  풀숲    │ │ 풀숲 !  │          │
│ ──────────────────────────────── │   │ └─────────┘ └─────────┘          │
│ 판정: 스라크 Lv.13 · HP 72%        │   │ ┌─────────┐ ┌─────────┐          │
└──────────────────────────────────┘   │ │  풀숲    │ │  풀숲    │          │
                                       │ └─────────┘ └─────────┘          │
                                       │ [ 그만두고 심사 받기 ]             │
                                       └──────────────────────────────────┘
```

### 3-2. 사파리존
1. 나들이 → 사파리존 → 구역 고르기(패널 목록, 구역마다 대표 3종 아이콘) → `입장 · 100W` → 사파리볼 30개.
2. 홈 LCD = 그 구역 그림 + `◓×30`. **60~150걸음마다** 풀숲이 흔들리며 무언가 나타남 → LCD에 `!`, 메뉴 막대 `·!`. 누르지 않으면 300걸음 뒤 `...가 가 버렸다`.
3. 홈에서 ●(또는 패널 `다가가기`) → 사파리 배틀. 내 쪽에 포켓몬 없음(트레이너 뒷모습 자리는 비워 둠), 상대 HP 상자 대신 **기분 표시**(먹는 중 = 도트 ♥, 화남 = 도트 `#`).
4. 패널 버튼 4개: **사파리볼 ×n / 먹이 / 진흙 / 도망**. 턴마다 도망 판정. 잡으면 워커로(`keep`), 도망가면 홈으로.
5. 볼이 0이 되거나 `나가기`를 누르면 끝(걸음 · 시간 제한 없음).

```
┌ LCD ─────────────────────────────┐   ┌ 패널 ───────────────────────────┐
│ 사파리 · 초원     ◓×23          │   │ 야생 럭키가 나타났다!             │
│              [럭키 앞모습]  ♥    │   │ ┌──────────────┐ ┌───────┐       │
│        ___발판___               │   │ │ 사파리볼 ×23  │ │ 먹이   │       │
│ ___발판___  (내 쪽 비어 있음)    │   │ └──────────────┘ └───────┘       │
│ 럭키는 먹이를 먹고 있다!          │   │ ┌──────────────┐ ┌───────┐       │
└──────────────────────────────────┘   │ │ 진흙          │ │ 도망   │       │
                                       │ └──────────────┘ └───────┘       │
                                       └──────────────────────────────────┘
```

### 3-3. 포켓슬론
1. 나들이 → 포켓슬론 → 종목 목록(오늘 최고 기록, 오늘 남은 보상 판 수) → 고르면 3초 카운트다운.
2. 종목(1차 3개):
   - **허들 대시**(스피드 · 점프): 코스 그림(들판) 위를 동료 걷기 도트가 오른쪽으로 달리고 허들이 다가옴. **패널의 큰 버튼 하나(= ● · space · 클릭)** 로 점프. 허들 바로 앞에서 뛰면 가속(4단계까지 — 원작처럼), 부딪치면 가속이 사라지고 잠깐 느려짐.
   - **블록 격파**(파워): 10초 동안 큰 버튼 연타. **워커 창이 키 창일 때만 시작**(다른 앱에 글자가 찍히지 않게). 블록이 쌓인 그림이 금 가고 깨짐.
   - **릴레이 런**(체력): "지금부터 3분, 평소처럼 일하세요". 워커는 입력 **횟수**만 셈 → 10초마다 걸음 수만큼 동료가 달림. 한 칸의 상한은 체력 별로 정해져서 **몰아치기보다 꾸준함**이 이김. 워커를 볼 필요 없음(끝나면 `.say` + 메뉴 막대 `·!`).
3. 결과: 기록 · 슬론 포인트(+오늘 NPC 기록을 넘으면 +100) · 최고 기록 경신 표시.
4. 교환: **BP 교환소 옆 "슬론 교환소"**(상점 화면 재사용, 화폐만 P). 품목은 원작 요일표.

```
┌ LCD ─────────────────────────────┐   ┌ 패널 ───────────────────────────┐
│ 허들 대시   23.4초   가속 ▸▸▸    │   │ 스피드★3 · 점프★4 (피카츄)        │
│  (들판 그림)                      │   │ ┌──────────────────────────────┐ │
│   피카츄→      ▮        ▮        │   │ │          점프  (●)            │ │
│ ════════════════════════════════ │   │ └──────────────────────────────┘ │
└──────────────────────────────────┘   └──────────────────────────────────┘
```

## 4. 규칙 · 수치 초안 (모두 한 곳의 상수 — 조정 손잡이)

### 4-1. 해금 · 비용 · 페이스 (기존 수치에 맞춤)

| | 해금 | 비용 | 한 판 길이 | 보상 크기 |

| 대회 | 누적 200W(아름다운 해변과 같은 때). 전국도감 표(레벨 24~36, 목·토 호연·신오 벌레)는 **도감 150종** | 무료, 대회 날 1번(주 3번) | 20분(실제 시간) · 찾기 30걸음마다 | 1위 진화의 돌(상점 1000W 값) + 판정 포켓몬 |

### 4-2. 벌레잡기 대회
- **출현표**(날짜 무관 / 전국도감 뒤 화·목·토), 원작 그대로 40줄을 Swift 상수로:
  - 전: 캐터피 · 뿔충이 20% (7~18) · 단데기 · 딱충이 10% (9~18) · 버터플 · 독침붕 (12~15) · 콘팡(10~16) · 파라스(10~17) · 스라크 · 쁘사이저 5% (13~14).
    ※ 버터플·독침붕과 콘팡·파라스의 10%/5%가 Serebii와 Bulbapedia에서 서로 반대 → **Serebii(= 2세대와 같은 쪽)로 결정 제안**.
  - 후 · 화: 같은 종, 레벨 24~36대 / 목: 개무소 · 실쿤 · 토중몬 · 볼비트 · 귀뚤뚜기 · 귀뚤톡크 · 독케일 · 세꿀버리 · 스라크 · 쁘사이저 / 토: 목요일에서 실쿤→카스쿤, 볼비트→네오비트, 독케일→뷰티플라이.
- **점수**(원작): `lv * 100 / 그 표의 최대 레벨 + ivSum * 100 / 186 + hp * 100 / maxHP + 희귀도` — 희귀도 60(캐터피 · 단데기 · 뿔충이 · 딱충이 · 개무소 · 실쿤 · 카스쿤 · 귀뚤뚜기), 100(스라크 · 쁘사이저), 그 밖 80.
- **포획**: 기존 4세대 공식 `throwBall(1.5)`. 가득 찬 HP로 던지면 스라크(포획률 45) 볼 1개당 ≈16%, 캐터피(255) ≈59%. 약하게 만들면 잡기 쉬워지지만 HP 점수가 줄어듦 = 이 대회의 핵심 고민.
- **NPC**: 10명(엘리트 트레이너 · 애호가 · 반바지 꼬마 · 캠핑보이 · 곤충채집소년 ×4 · 모범 소년 · 피크닉걸, 이름은 타워처럼 한국 이름) 중 날짜로 5명. 각자 같은 출현표 · 같은 공식으로 **2번 잡아서 좋은 쪽**. 시뮬레이션(2만 판): NPC 1위 점수 중앙값 321 (25~75%: 308~335). 스라크/쁘사이저를 HP 가득으로 잡으면 ~350 → 이길 만함.
- 이로치 1/64(다른 곳과 같음). 판정 포켓몬 말고는 레이더 연쇄 · 경험치 규칙 그대로(연쇄는 없음).

### 4-3. 사파리존
- 포획 = 기존 공식, 사파리볼 ×1.5, 상대 HP는 늘 가득(포획률 × 1/3), 포획률 × 단계 배수 `(2+n)/2 · 2/(2−n)`(±6).
- 도망 = 턴 시작에 `x = 0...254`, `x <= 도망률 × 단계 배수`면 턴 끝에 도망. 도망률은 종별 60/90/120/150(원작표).
- 계산해 보면(가득 찬 HP): 포획률 255 → 볼 1개당 59% · 진흙 +1이면 81% / 45 → 16% · 22% / 도망률 90 → 턴마다 36% · 먹이 −1이면 24%.
  한 만남에서 **꼭 잡고 싶으면 볼 연타**(45/90: 34%), **볼을 아끼려면 진흙 먼저**(볼 1개당 0.23마리 vs 볼만 0.16). 먹이는 원작에서도 약함 — 그대로 둠(§10 Q6).
- 만남 간격 60~150걸음, 기다림 300걸음. 레벨 = 원작 구역표 레벨. 게임 속 시간(아침 · 낮 · 밤 = `state.hour`)으로 원작 시간대별 출현을 가림.
- 2차: **블록**(평원 · 숲 · 바위 · 물가, 구역마다 30개까지) + **구역 업그레이드**(그 구역에서 사파리를 한 실제 날 수 — 원작표: 평원 ×2 10일 · ×3 50일 …). PokeAPI에 `johto-safari-blocks-<종류>-min-N` 조건이 이미 있어서 그대로 씀.

### 4-4. 포켓슬론
- 성능 별: PokeAPI `pokemon_form_pokeathlon_stats.csv`(종마다 5가지 × 최소 · 기본 · 최대, 1~5; 1~493번은 폼 id = 도감 번호 확인함) + `nature_pokeathlon_stats.csv`(성격 보정). 규토리 주스가 없으니 **기본 별 + 성격이 올리는 쪽이면 최대 쪽으로 1**.
- 허들 대시: 100m, 허들 12개, 기본 속도 `2 + 0.5 × 스피드★` m/s, 가속 +10%씩 4단계, 점프 거리 = 점프★. 포인트 = `3833 ÷ 초`(원작 11500 ÷ 3마리 합계 초를 1마리로). 30초면 128P.
- 블록 격파: 10초, 블록 하나에 `7 − 파워★`번. 포인트 = 깬 블록 × 7(초당 7번 연타, 파워★3 → 17개 → 119P).
- 릴레이 런: 3분 = 10초 18칸, 칸마다 `min(걸음, 20 + 5 × 체력★)`. 포인트 = 합 ÷ 3(10초에 20번 꾸준히 → 120P).
- 오늘의 NPC 기록(날짜 시드)을 넘으면 +100(원작 1위 보너스). 하루 3판이 넘으면 기록만 남고 포인트는 0.
- 슬론 교환소(원작 요일표를 앱에 있는 도구로): 월 달의돌 3,000 · 이상한사탕 2,000 · 태양의돌 3,000 · 물의돌 2,500 · 빛의돌 3,000 · 어둠의돌 3,000 · 풀회복약 500 · 튼튼밀크 100 · 왕의징표석 3,000 … 일요일까지 7줄(Serebii 표 그대로 옮김).

## 8. 멀티 확장 여지

지금 서버 · 코드 교환은 **만들지 않는다**. 대신 나중에 붙일 수 있게 세 가지만 지켜 둔다(비용 거의 0).

1. **날짜 시드**: 대회 NPC 5명과 점수, 포켓슬론 NPC 기록 · 허들 배치, 슬론 교환소 품목을 모두 `fnv("\(day)|contest")` 같은 문자열 해시로(02 · 03 기획안과 같은 규칙, Swift `hashValue` 금지). → **같은 날엔 모두가 같은 대회**를 치러서 점수를 비교할 수 있음.
2. **결과 = 작은 값 타입**: `OutingResult { v, kind, day, score, dex, trainerID }`를 `outingLog`에. `trainerID`는 03 레이드 기획안의 것을 같이 씀(→ 03-raid.md §6).
3. **입력 기록 가능**: 허들 대시는 (시드 + 누른 시각 배열)만 있으면 똑같이 다시 돌게 — 배틀의 "시드로 다시 도는 beat"와 같은 생각.

그다음 단계:
- **친구 결과 코드**(서버 없음): 오늘 대회 결과를 12자리 코드로 → 친구가 붙여 넣으면 **그 친구가 오늘 심사에 6번째 참가자로** 나옴.
- **친구 사파리**(XY의 프렌드 사파리): 친구 코드에서 타입 하나 · 종 3개를 정해 "친구 구역"이 열림. 역시 서버 없음.
- **고스트 레이스**: 허들 대시 입력 기록을 공유 → 친구의 고스트와 같이 달림.
- **작은 서버**(Cloudflare Worker + KV 정도): `POST {day, kind, score, trainerID}` / `GET 오늘 순위` — 요일 대회 순위표.

## 10. 리스크 · 열린 질문 (추천 기본값 ▶)

1. **대회 요일은 무엇으로?** 실제 달력 / 게임 속 날(1,000걸음). ▶ **실제 달력 화·목·토**(원작도 DS 시계. "오늘은 대회 날"이 이 모듈의 재미).
2. **대회 20분은?** 실제 20분 / 1,000걸음. ▶ **실제 20분**(원작 그대로. 일에 빠져 잊어도 그건 원작도 같음).
3. **찾기 30걸음 대기가 필요한가?** ▶ **둔다**(20분 동안 몰아치지 않고 "일하다 한 번씩"이 되게. 0으로 바꾸기 쉬움).
4. **교체 확인에 점수를 보여 줄까?** ▶ **안 보여 줌**(원작처럼 Lv · HP% · V만. 심사 때 처음 공개).
5. **동료 레벨이 너무 높으면?** 벌레를 한 방에 쓰러뜨림. ▶ **원작대로 둠** — HP 가득일 때 던지는 게 오히려 최고 점수라 문제가 안 됨. 레벨 상한은 두지 않음.
6. **사파리 먹이 · 진흙 수치를 손볼까?** 원작 수치로는 먹이가 거의 쓸모없음. ▶ **원작 그대로**(진흙 = 볼 아끼기, 볼 연타 = 이번 판에 걸기로 이미 고민거리가 있음).
7. **사파리 입장료?** ▶ **100W**(한 판 동안 버는 W와 비슷).
8. **포켓슬론 화폐?** 따로 슬론 포인트 + 요일 교환소 / 그냥 W. ▶ **슬론 포인트**(원작의 "요일마다 바뀌는 상품"이 다시 들르게 만듦). 이름은 한국판 명칭 확인 전까지 "슬론 포인트(P)".
