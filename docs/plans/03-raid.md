# 03 · 레이드 — 이번 주의 전설 — 기획안

> 상태: 초안 (검토 전) · 의존 없음(단독 출시 가능). 02 로켓단과 `fnv` 헬퍼·칠색조 정책을(→ 02-rocket-story.md), 01·04·05·07과 메뉴 칸을 같이 정한다(→ README.md '메뉴 타일'). 06 업적은 `raidsCleared`를 읽음.

## 1. 한 줄 요약 · 왜 재미있나

**매주 월요일 큰 전설 하나가 "보스"로 나타난다. 보스의 HP는 여러 판에 걸쳐 그대로 남고, 걸어서 모은 파워 1칸으로 한 판씩 싸워 깎는다. 다 깎으면 프리미어볼 3개로 잡을 기회.**

- **한눈에 끝나는 한 판**: 한 판 = 타워 파티 3마리로 최대 6턴(약 40초). 져도 **깎은 HP는 남는다**. 그래서 일하다 잠깐 볼 때 "한 대만 더"가 성립한다.
- **걸음이 곧 탄약**: 1,000걸음 = 파워 1칸(최대 3칸). 게이지가 차면 알림이 온다. 쌓아 둘 수 있는 건 3칸까지라 두세 시간에 한 번 들여다보게 되는데, 이게 데스크 펫에 맞는 리듬이다.
- **늘 성장하는 느낌**: 줄(bar)을 하나 깰 때마다 +1 BP, 경험치도 들어온다. 주말에 보스를 못 잡아도 한 주 동안 한 일은 이미 보상으로 받았다.
- **수집 목표와 이어짐**: 레이드로만 **4V 전설**(★5)을 얻을 수 있다. 이로치는 1/64. 매주 보스가 돌아가며 바뀌고, 다음 주 보스가 누구인지 미리 보여 줘서 기다리는 재미가 있다.
- **나중에 친구와**: 보스와 한 판의 결과를 "주 id + 시드"로 정해 두면, 나중에 친구들이 **같은 보스의 HP를 함께 깎는** 비동기 레이드로 바꿀 수 있다(8장).

## 3. 플레이 흐름

### 3.1 한 주의 모양
1. **월요일 00:00(KST)**: 새 보스가 나온다. 알림 `이번 주 보스: 가이오가 ★5` (종류 `raid`).
2. 걷는 동안 파워가 찬다(1,000걸음에 1칸). **3칸이 되면** 알림 `레이드 파워가 가득! 가이오가에게 도전`.
3. 메뉴 → **레이드** 타일을 누르면 로비. 파워가 1칸 이상이면 **도전**을 누른다 → 한 판 → 결과 한 줄 → 로비로 돌아온다.
4. HP가 0이 되면 **포획 단계**: 프리미어볼 3개를 던진다. 잡든 놓치든 클리어 보상이 들어오고, 원하면 2회차(같은 보스, HP 가득, 보상 절반)를 시작한다.
5. 일요일이 끝날 때까지 못 잡으면 보스는 떠난다. 그동안 받은 줄 BP·경험치는 그대로 남는다.

### 3.2 로비 (Screen `.raid`)

LCD는 보는 곳이다. 보스의 코스 배틀 배경 위에 보스가 서 있고 오라가 두르며, 레이드 HP 바가 보인다.
```
LCD 96×64 ─────────────────────────┐   제목 줄: 레이드 ★5 · 4일 남음
│가이오가 Lv.70           ★★★★★│
│██████████████░░░░░░░░░  7/12줄 │  ← 레이드 전체 HP (줄 단위 눈금)
│                  ╭──────╮      │
│   ~ 물결 ~       │ 보스 │      │  ← HGSS 앞모습 + 오라(stageGlow)
│                  ╰──────╯      │
│ 파워 ■■□          다음 칸 420걸음│
└────────────────────────────────┘
```
패널(누르는 곳)의 모양은 배틀 타워 로비(`drawTower`)와 같다.
```
┌ 이번 주 가이오가 · 다음 주 그란돈 ───┐
│ 남은 HP ██████████░░░░░  7 / 12줄   │
│ 파워 ■ ■ □   다음 칸까지 420걸음     │
│ [아이콘] 피카츄        Lv.62        │  ← Walk.party() (타워와 같은 3마리)
│ [아이콘] 갸라도스      Lv.58        │
│ [아이콘] 메타그로스    Lv.60        │
│ 내 기록 9판 · 5.3줄 · 한 판 최고 1.8줄 │
│ [   도전 · 파워 1칸   ]  [나가기]   │
└────────────────────────────────────┘
```
- 첫 판을 치르기 전에는 ◀ ▶로 ★을 바꿀 수 있다(기본값은 파티 평균으로 자동, 4.1). 첫 판을 치르면 그 주 동안 ★이 고정된다.
- 파워가 0이면 버튼이 흐려지고 `파워가 없다 (1,000걸음마다 1칸)`가 뜬다.
- 포획을 기다리는 중이면 버튼이 **볼 던지기 · 남은 3**으로 바뀐다.

### 3.3 한 판
- 시작 연출은 야생 전설과 같다: 화면 반전 두 번 → `보스 가이오가가 나타났다!` → 잔비 특성 발동.
- 메뉴는 타워형 **공격 / 도구 / 교체 / 후퇴**다. 볼 버튼은 없다.
- HUD는 타워와 같은 자리에 있다. 이름 옆 보석 3개(타워에서 남은 볼을 보여 주는 `gem`)가 **이번 판에서 깰 수 있는 줄**을 나타낸다. 제목 줄은 `레이드 ★5 · 3/6턴`.
- 줄이 깨지면 `.fainted(.it)` 다음에 `보스 가이오가가 다시 일어섰다!`가 뜨고 다음 줄이 이어진다. 상태이상과 능력 랭크는 초기화되고, 경험치(`gained`)는 줄마다 들어온다.
- 판이 끝나는 경우는 넷이다. ① 6턴이 지남: `가이오가의 기세에 밀려났다!` ② 파티가 전멸함(부활초·기력의조각은 평소처럼 자동으로 씀) ③ 후퇴 ④ 이번 판에 깰 수 있는 줄(최대 3)을 다 깸. 어느 경우든 **깎은 HP는 남는다**.
- 결과는 `.say(["가이오가에게 612 데미지!", "2.4줄 · +2 BP"])`로 보여 주고 로비로 돌아간다.

### 3.4 포획
```
LCD: 지친 보스(흔들림) + 프리미어볼 ●●○     패널: [ 볼 던지기 · 남은 2 ]  한 개당 30%
```
- 한 번 던질 때마다 `.beats`로 `.thrown(shakes:)` → `.caught` / `.broke`가 재생된다. 볼 연출은 `BallFX`를 그대로 쓴다.
- 잡으면 `✦ 반짝! ✦`(이로치일 때) → `keep()`으로 워커(또는 상자)에 넣는다. 3개를 다 놓치면 `가이오가는 바다로 돌아갔다…` 두 경우 모두 클리어 보상을 준다.

## 4. 규칙 · 수치 초안

### 4.1 ★ 단계
| | ★3 | ★4 | ★5 |
|---|---|---|---|
| 보스 레벨 | 40 | 50 (HGSS 가이오가) | 70 (HGSS 반대 버전 루기아) |
| 줄 수 (1줄 = 보스 실제 최대 HP) | 8 | 10 | 12 |
| 1줄 HP 예 (루기아, HP 개체값 31) | 147 | 181 | 250 (기라티나 311) |
| 자동 선택 (타워 파티 평균 Lv) | < 45 | 45–59 | ≥ 60 |
| 확정 V (잡히는 개체) | 3 | 3 | 4 |

### 4.2 파워 · 한 판
| 항목 | 값 | 근거 |
|---|---|---|
| 파워 1칸 | **1,000걸음** | 50W어치 = 배틀 타워 참가비와 같은 양이고, 게임 속 하루(`dayLength`)와도 같다 |
| 최대 | 3칸 (3,000걸음) | 넘치는 걸음은 버려진다. 그래서 "가득" 알림이 들여다볼 이유가 된다 |
| 한 판 비용 | 1칸 (W는 안 씀) | W 경제(레이더·상점·타워)와 겹치지 않음 |
| 턴 제한 | **6턴** | 한눈에 끝나는 길이. 소드실드는 10턴 |
| 한 판에 깰 수 있는 줄 | 최대 3줄 | Lv.100 스위퍼가 두 판 만에 끝내지 못하게. ★5 최소 4판 |
| 파티 | `Walk.party()` (동료 + 가장 강한 2마리) | 타워와 같고, 고르는 UI가 필요 없음 |
| 도구 | 배틀 도구 사용 가능, 부활 자동 | BP 교환소 도구를 쓸 곳이 생김 |
| 보스 AI | 트레이너 AI(`foeChoice`의 점수 계산) | 야생처럼 무작위로 고르면 보스답지 않음 |
| 보스 면역 | 일격기(12·32·90·329), 멸망의노래 카운트, 길동무 | 한 줄을 공짜로 깨는 수를 막음. 다이맥스 포켓몬이 일격기에 면역인 것을 따옴 |

**속도 감각**(★5, 파티 Lv.60 기준 추정: 턴당 60~80 데미지, 3마리가 각각 2턴쯤 버팀): 한 판에 약 1.5줄 → **8판 ≈ 8,000걸음**. 하루에 1~2만 걸음 치는 사람이라면 1~2일, 적게 쳐도 한 주 안에 끝난다. Lv.80 이상이면 줄 상한(3줄)에 걸려 4판이 걸린다. 파티가 약하면 ★이 자동으로 내려간다.

### 4.3 보상
| | ★3 | ★4 | ★5 |
|---|---|---|---|
| 줄 하나 깰 때마다 | +1 BP | +1 BP | +1 BP |
| 클리어 | 10 BP · 이상한사탕 ×2 | 15 BP · 이상한사탕 ×3 · PP맥스 | 25 BP · 이상한사탕 ×5 · **은색병뚜껑** |
| 한 주 합 (1회차) | 18 BP | 25 BP | **37 BP** |
| 2회차부터 | 줄 BP는 그대로, 클리어 BP·도구는 절반(내림, 병뚜껑 없음) | | |

비교하면, 타워 7연승 한 세트 = 10 BP, 뮤츠 = 300 BP, 은색병뚜껑 = 25 BP다. ★5 한 주는 타워 세 세트쯤이고, 걸음으로 치르니 W는 들지 않는다.

### 4.4 포획
- 프리미어볼 3개. 한 개당 **★3 50% / ★4 40% / ★5 30%**, 세 개를 합치면 87.5% / 78.4% / 65.7%.
- **이미 가진 종이면 확률이 절반**(전설 코스의 "다 잡은 뒤 절반" 규칙과 같음): 57.8% / 48.8% / 38.6%.
- 잡히는 개체는 잡는 순간 새로 뽑는다: `Mon.wild(dex, level: ★레벨, shiny: 1/64, perfect: ★5 ? 4 : 3)`. 싸운 보스 개체와는 따로다(GO처럼 각자의 개체).
- 4세대 포획 공식 대신 고정 확률을 쓴다. 전설의 포획률 3이면 HP 1에서도 한 개당 약 3.6%라, 한 주 동안 한 일에 대한 보상으로는 너무 가혹하다.

### 4.5 보스 순서 (기본 7종, 주 번호 % 7)
루기아 → 가이오가 → 그란돈 → 레쿠쟈 → 디아루가 → 펄기아 → 기라티나. 배틀 배경은 그 전설이 나오는 코스의 `art`(`courses.first { $0.legends.contains(dex) }`)를 쓴다: 루기아 town(시작의 방), 가이오가·그란돈·레쿠쟈 beach, 디아루가·펄기아·기라티나 cave. 기술은 `Mon.defaultMoves(dex, level)`이다. 칠색조·뮤츠는 상점 전용이라 기본 풀에서 뺐다(10장 Q2).

### 4.6 해금
**도감 잡음 150종**(첫 전설 코스 "전설의 새 둥지"와 같은 때)에 해금된다. 해금되면 메뉴 타일이 생기고 `unlock` 알림이 오며, 그때부터 파워가 차기 시작한다.

## 6. 데이터 · 저장

```swift
/// This week's raid. Solo now: `dealt` is this walker's own damage, so a server can later add friends' on top.
struct Raid: Codable, Equatable {
    var week: String            // "2026-W40": ISO week in Asia/Seoul — the raid's id
    var tier: Int               // 3 / 4 / 5: auto from the party, locked by the first fight
    var boss: Mon               // the one everyone fights, made once from Seeded(fnv("raid|\(week)|\(tier)")) and kept
    var bars: Int               // HP pool = bars × boss.stats[0]
    var dealt = 0               // damage this round (HP units); 0 again when a round is beaten
    var fights = 0              // fights this week: part of each fight's seed
    var clears = 0              // rounds beaten this week (2회차 on: half rewards)
    var best = 0                // most damage in one fight
    var balls: Int? = nil       // a catch waiting: premier balls left
}
// Walk (all Optional: older saves decode as they are; `version` stays 1)
var raid: Raid? = nil
var raidPower: Int? = nil       // steps banked, 0...3000 (1,000 = 1칸); added in walk(_:at:) once unlocked
var trainerID: UInt64? = nil    // random, made once: fight seeds now, the friend code later
var raidsCleared: Int? = nil    // lifetime (트레이너 카드, 06 업적 리본)
```
- **주가 바뀔 때**: 로비를 열거나 `tick`이 돌 때 `raid?.week != Walk.raidWeek(now)`이면 새 `Raid`를 만든다. 지난 주 것은 버리고 `raidsCleared`만 남긴다.
- **보스는 저장해 둔다**: 매번 다시 만들지 않는다. `Mon.wild`가 쓰는 `Int.random(in:using:)`는 Swift 버전에 따라 결과가 달라질 수 있어서, 주 중간에 앱을 업데이트해도 보스가 바뀌지 않게 한다.
- **판 시드**: `fnv("\(week)|\(tier)|\(trainerID)|\(fights)")`. 같은 파티와 같은 선택이면 같은 데미지가 나온다(셀프테스트).
- **남은 HP** = `bars × boss.stats[0] − dealt`. 멀티에서는 `dealt` 자리에 서버가 준 합계를 넣으면 된다. 식은 바뀌지 않는다.
- 판마다 전투 기록(선택 목록)은 **지금은 저장하지 않는다**. 필요해지는 건 서버가 생길 때뿐이다.

## 8. 멀티 확장 여지

**설계의 핵심**: 레이드의 정체성(주 + ★)이 서버 없이 모든 기기에서 같게 나오고, 각자의 기여(`dealt`)는 더하기만 하면 되는 형태다.

- **친구 코드**: `trainerID`를 DS처럼 12자리로 보여 준다(`1234-5678-9012`, 마지막 자리는 검사 숫자). 트레이너 카드에 표시.
- **같은 보스**: 모두 `"raid|2026-W40|5"` → 같은 보스. 서버가 있으면 서버가 보스 JSON을 올려 두고 고정한다(Swift 버전 차이를 없앰).
- **HP 공유**: 남은 HP = `bars × HP − Σ 모두의 dealt`. 그룹 인원이 n명(최대 4, 소드실드처럼)이면 `bars = 기본 × (1 + 0.5(n−1))`로 늘린다.
- **기여에 따른 볼**: HP가 0이 되면 한 판이라도 친 사람은 모두 포획 단계를 얻는다(GO처럼 비동기라서 나중에 열어도 `친구들이 가이오가를 쓰러뜨렸다! 잡을 기회`). 볼 = 3 + (내 몫 ≥ 1/n이면 1) + (최다 기여면 1).
- **검증(선택)**: 한 판 기록 = `{week, tier, trainerID, n, party:[Mon], choices:[String], dealt}`. 시드는 다시 계산할 수 있고, `Sources/Model`·`Battle`·`Data`는 Foundation만 쓰므로 Linux Swift 서버에서 다시 돌려 확인할 수 있다. 친구끼리라면 믿고 넘어가도 된다.
- **두 가지 길**:
  - A. **서버 없음**: 주간 "기여 코드"(`R40·5·<id>·<dealt>·<검사>` base32 한 줄)를 메신저로 주고받고, 우클릭 → 레이드 → 친구 기여 붙여넣기로 합산한다. 믿음에 기대는 방식이고 인프라가 0이다.
  - B. **작은 서버**: Cloudflare Worker + KV 정도, 엔드포인트 3개(`GET /raid/:week`, `POST /raid/:week/fight`, `GET /group/:code`). **로비를 열 때만** 요청한다(백그라운드 통신 없음). 켜는 건 사용자가 고르고, 지금 앱의 "네트워크 0"은 유지한다.
- **지금 해 둘 것 (거의 비용 0)**: ① `trainerID`, ② 판 시드 공식 + `fightRng` 분리, ③ 보스를 저장, ④ `dealt`를 "내 몫"으로 둠("보스 HP" 필드를 따로 만들지 않음), ⑤ 주 키를 고정 시간대로. 서버·코드 교환·전투 기록은 **지금 만들지 않는다**.
