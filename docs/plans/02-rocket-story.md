# 02 · 로켓단 이야기 — 기획안

> 상태: 초안 (검토 전) · 의존: 01 체육관 여정(배지 수, → 01-gym-journey.md). 01 없이도 누적 W 폴백으로 먼저 출시 가능. 공통 시스템(홈 배너 · 대사 화면 · 배틀 종류 · 선물 기기 색)은 → README.md.

## 1. 한 줄 요약 · 왜 재미있나

**체육관과 체육관 사이에 HGSS 로켓단 사건 4장(+에필로그)이 "막간"으로 끼어든다.** 한 장은 짧은 대사 컷(LCD 장면 + 패널 대사) → 레이더에 숨은 로켓단 조무래기 몇 명 → 간부 배틀 → 보상으로 끝난다.

- **보는 만큼만 진행**: 이야기는 먼저 끼어들지 않는다. 새 장이 열리면 홈 패널에 배너 한 줄(`R 1장 야돈의 우물 ▶`)과 알림만 뜨고, 누를 때 재생된다. 일하다 잠깐 볼 때 1~2분이면 한 장면이 끝난다.
- **새 모드가 아니라 기존 루프에 섞인다**: 조무래기는 늘 하던 **포켓 레이더**의 풀숲에서 튀어나오고, 간부는 **배틀 타워 엔진**(3 대 3, 교체)으로 싸운다. 새로 배울 조작이 없다.
- **적게 써서 많이 느끼게**: 전체 대사 약 40줄. 동료 이름·코스·날씨를 끼워 넣어 같은 대사가 "내 이야기"가 되고, 끝나면 세계가 조금 바뀐다(야돈이 돌아옴, 빨간 갸라도스가 상자에, 라디오가 조용해짐).
- **수집 보상과 연결**: 야돈 + 왕의징표석(→ 커넥트로 야도킹), **이로치 확정 빨간 갸라도스**, 무지개날개(칠색조 1회), 기기 색.

## 2. 원작(HGSS) 참고

| 원작 사건 | 원작 시점 | 여기서 | 충실한 것 | 바꾼 것 |
|---|---|---|---|---|
| 야돈의 우물 (고동마을) — 꼬리 자르기 | 1번째 배지 뒤, 호일 체육관 직전 | **1장** | 간부 **랜스**(Proton), 조무래기, 야돈 | 우물 탐색 → 레이더에서 조무래기 3명 찾기 |
| 분노의 호수 — 빨간 갸라도스 · 목호 등장 | 6번째 배지 무렵, 황토마을 전 | **2장 전반** | **빨간 갸라도스 Lv.30 이로치 확정**, 쓰러뜨려도 빨간비늘, 목호(Lance) | 호수 코스로 옮길 필요 없음(장면 배경만 호수) |
| 황토마을 로켓단 아지트 (강제 진화 전파, 붐볼 발전기) | 같은 시기 | **2장 후반** | 간부 **아테나**(Ariana), 목호와 공동 작전 | 붐볼 발전기 생략(글로만 한 줄) |
| 금빛시티 라디오탑 점거 ("비주기 님 돌아와 주세요" 방송) | 7번째 배지 뒤 | **3장** | 층을 올라가는 연속 배틀, 국장으로 변장한 **람다**(Petrel), 꼭대기의 **아폴로**(Archer), 로켓단 해산 선언 | 5층 = 5연전(타워처럼 사이사이 HP 회복), 지하 창고·카드키 생략 |
| 세레비 이벤트 — 과거의 **비주기** (HGSS 배포 세레비 필요) | 클리어 후 | **에필로그** | 세레비가 있어야 열림, 비주기 배틀 | 배포 대신 **세레비 보유**(환상의 숲 코스, 도감 300) |

원작 대사는 인용하지 않고 **이름·장소·사건만 원작**, 대사는 짧게 새로 쓴다(정확성·저작권 부담 모두 줄임).

## 3. 플레이 흐름

### 3.1 한 장의 모양 (모든 장 공통)

```
[문이 열림] 배지/누적W 조건 + 이전 장 끝난 뒤 1,000걸음
   → 알림 "로켓단이 나타났다 · 1장 야돈의 우물" + 홈 동료 머리 위 `!` + 홈 패널 배너
[도입]  배너 클릭(홈 ●는 쓰다듬기 그대로 — README) → 대사 컷 3~5장 (● / 클릭 = 다음, ↩ = 건너뛰기)
[추적]  레이더를 평소처럼 — 첫 발견(연쇄 0)의 풀숲에서 가끔 조무래기가 튀어나옴 → 트레이너 배틀
        배너: "조무래기 1/3 · 레이더에 숨어 있다"
[결판]  3명 다 이기면 배너가 "▶ 간부 랜스에게" → 대사 1~2장 → 3 대 3 배틀
[마무리] 승리 → 대사 1~2장 → 보상 → 트레이너 카드 '이야기' 탭에 기록
        패배 → 잃는 것 없음, 배너 그대로(다시 ▶)
```

### 3.2 화면

홈 (이야기 대기 중) — 패널에 배너 한 줄이 생겨 카드가 그만큼 아래로 늘어난다(없으면 원래 크기):

```
 LCD 96×64                              패널
┌──────────────────────────────┐      ┌──────────────────────────────────┐
│ (코스 그림)        !          │      │ [R] 1장 · 야돈의 우물          ▶ │
│   동료가 걷다 멈춰 앞을 봄    │      │     조무래기 1/3 · 레이더에 숨어 있다│
│                    (동료 도트) │      └──────────────────────────────────┘
└──────────────────────────────┘
```

대사 컷 `.story` — LCD는 **장면 + 짧은 한 줄**, 읽을 대사는 **패널**(시스템 글꼴, 넓음). 3초 자동 넘김 없음:

```
 LCD 96×64                              패널
┌──────────────────────────────┐      ┌──────────────────────────────────┐
│ 야돈의 우물            2/4    │      │ 로켓단 조무래기                   │
│ ┌────────┐          ┌─────┐  │      │ 야돈 꼬리가 비싸게 팔린다고.      │
│ │조무래기 │          │ 야돈 │  │      │ 꼬마는 빠져 있어!                 │
│ │(상반신) │          └─────┘  │      │                                  │
│─┴────────┴───────────────────│      │ [ ↩ 건너뛰기 ]        [ 다음 ▶ ] │
│   꼬리는 우리가 접수!         │      └──────────────────────────────────┘
└──────────────────────────────┘
```
배경은 장의 `Art`(우물 `.cave`, 호수 `.lake`, 아지트 `.town`의 밤, 라디오탑은 타워 홀)를 `battleGround`로, 인물은 80×80 트레이너 그림의 윗부분, 포켓몬은 `showMon`.

트레이너 카드 **이야기** 탭(06 리본 탭과 같이 들어오면 5번째 — → README.md '트레이너 카드 탭'. 07 탐험 기록도 이 탭에) (다시 보기 = 대사 컷만 재생, 배틀 없음):

```
[트레이너 카드][최근 7일][알][이야기]
 ✓ 1장 야돈의 우물            다시 보기 ▶
 ● 2장 분노의 호수            조무래기 2/3
 · 3장 ???                    배지 7개
 · 에필로그 ???               세레비
 조무래기 7명 · 간부 1명 · 빨간비늘 ✓
```

라디오탑(3장)은 레이더 대신 **층 로비**(타워 로비 재사용): LCD "라디오탑 3F / 5F", 패널 `▶ 올라가기 · ↩ 나가기`. 층마다 1전, 사이에 HP 회복, 지면 그 층에서 멈춤(다음에 그 층부터).

### 3.3 대본 초안 (1장 전체 — 이 분량이 기준)

LCD 줄은 한글 9자 안팎(`textWidth ≤ 92`로 셀프테스트). `{동료}`는 조사까지 `josa()`로.

| # | 누구 · 그림 | LCD | 패널 |
|---|---|---|---|
| 1 | 나레이션 · 우물 + 빈 배경 | 고동마을 우물 | {동료}가 우물 쪽을 보며 코를 킁킁거린다. 늘 보이던 야돈들이 없다. |
| 2 | 조무래기 · 야돈 | 꼬리는 우리가 접수! | 야돈 꼬리가 비싸게 팔린다고. 꼬마는 빠져 있어! |
| 3 | 나레이션 · 동료 | {동료}!! | {동료}가 앞으로 나섰다. 조무래기들이 우물 여기저기로 흩어졌다 — 레이더로 찾아내자! |
| 4 | 간부 랜스 (보스 전) | 간부 랜스다. | 로켓단에서 제일 무서운 남자가 누군지 알려 주지. |
| 5 | 랜스 (승리 후) | ...오늘은 물러난다 | 흥, 이쯤 해 두지. 로켓단은 곧 다시 일어난다. |
| 6 | 나레이션 · 야돈 | 야돈이 돌아왔다 | 우물에 야돈들이 돌아왔다. 한 마리가 {동료}를 졸졸 따라온다! (야돈 · 왕의징표석) |

나머지 장은 같은 틀로 도입 3 + 보스 전 1 + 마무리 2 = 6컷씩:
- **2장** 호수가 붉게 일렁인다 → (빨간 갸라도스 배틀) → 목호: "억지로 진화시키는 전파가 있다. 황토마을이 수상해." → 조무래기 3 → 아테나 → 목호: "고맙다. 다음은 네 힘을 빌리지."
- **3장** 라디오에서 이상한 방송: "비주기 님, 돌아와 주십시오!" → 1~3F 조무래기 → 4F "나는 국장... 이 아니라 람다다!" → 5F 아폴로 → "비주기 님... 로켓단은 오늘로 해산한다."
- **에필로그** 세레비가 {동료}와 함께 빛에 싸인다 → 3년 전의 그날 → 비주기 → "...너 같은 아이가 있다면." (이야기 끝)

**조무래기 대사 풀 6줄**을 모든 장에서 돌려 씀(배틀 전·후 패널 한 줄): "로켓단을 얕보지 마라!" · "비주기 님을 위하여!" · "이런, 꼬마한테 지다니..." · "간부님께 보고해야겠다...!" · "우리 계획은 멈추지 않아!" · "얼굴 기억해 두겠다!". 배틀 인트로 "…가 승부를 걸어왔다!"는 BattleView가 이미 만든다.

## 4. 규칙 · 수치 초안

### 4.1 장별 표

| 장 | 열림 (01 있음) | 열림 (폴백: 누적 W `earned`) | 추적 | 보스 (파티 평균 Lv 기준) | 보상 |
|---|---|---|---|---|---|
| 1 야돈의 우물 | 배지 ≥ 1 | 500W (교외 해금과 같음) | 레이더 조무래기 3 | 랜스 3마리, 평균 +2 | 야돈 Lv.(동료−5, 최소 10) · 왕의징표석 · 300W |
| 2 분노의 호수 · 아지트 | 배지 ≥ 6 | 5,000W (호연 들판) | 빨간 갸라도스 → 레이더 조무래기 3 | 아테나 3마리, +3 | **빨간 갸라도스**(잡으면) · 빨간비늘(기념) · 하이퍼볼 ×5 · 500W |
| 3 라디오탑 | 배지 ≥ 7 | 10,000W (화산 길) | 층 1~3F 조무래기(2마리씩) | 4F 람다 +3 · 5F 아폴로 3마리 +5 | 무지개날개 → **칠색조 Lv.45 1회**(3V, 전설 규칙) · BP 10 |
| 에필로그 | 배지 8 + 세레비(251) 보유 | 세레비 보유 | — | 비주기 3마리, +8 | 기기 색 "로켓단 화이트"(흰 윗면·검은 띠) · 카드 칭호(= 06 리본 하나, → README.md) |

- **장 사이 간격**: 앞 장이 끝난 뒤 **1,000걸음(게임 속 하루)** 지나야 다음 장이 열림. 이미 배지·W가 많은 세이브도 한꺼번에 쏟아지지 않고 하루 한 장씩.
- **조무래기 만남**: 이야기가 추적 단계일 때 레이더 **첫 발견(연쇄 0)에서만** 1/3 확률로 야생 대신 조무래기. 3번 연속 안 나오면 4번째는 확정(`dry` 카운터). 연쇄 중엔 절대 안 나옴 → 연쇄·이로치 사냥은 그대로.
  - 기대값: 조무래기 1명 ≈ 레이더 2.4회 ≈ 24W. 한 장 ≈ 7회 ≈ 70W + 배틀 7판. 하루 1만 타(=500W)·레이더 5회라면 **한 장 1~2일**, 전체는 01의 배지 페이스를 따라감.
- **파티**: 조무래기·간부 모두 타워처럼 `party()`(동료 + 가장 강한 2마리). 조무래기는 2마리, 간부는 3마리. 경험치는 트레이너 1.5배(엔진 기존 규칙), BP·연승 없음.
- **상대 레벨**: 조무래기 = 파티 평균 −3 (최소 5), 간부 위 표. 종은 계열로 정하고 레벨에 맞춰 진화 단계(`towerFoes`의 단계 규칙).
  - 조무래기: 꼬렛·주뱃·또가스·아보·질퍽이·슬리프 계열
  - 랜스: 주뱃·또가스·니로우 / 아테나: 아보·니로우·또가스 / 람다: 또가스 ×2·질퍽이 / 아폴로: 델빌·주뱃·또가스 / 비주기: 페르시온·니드킹·니드퀸 — **원작 파티 확인 전 초안**
- **빨간 갸라도스**: 야생 배틀(`Mon.wild(130, level: 30, shiny: true)`), 원작처럼 개체값은 무작위. 잡거나 쓰러뜨리면 빨간비늘 + 다음 단계. 도망·패배면 다시 도전 가능(배너 그대로). 연쇄로 이어지지 않음.
- **패배**: 잃는 것 없음. 부활초·기력의조각은 기존처럼 자동.
- **W 비용**: 없음(레이더 10W는 원래 내던 것). 라디오탑도 참가비 없음.
- **W 보상**(300W · 500W)은 `watts`에만(`earned` 아님 — → README.md '보상 · 해금 층').

## 6. 데이터 · 저장

`Walk`에 선택 필드 하나 (옛 세이브는 `nil`로 로드):

```swift
var story: Story? = nil
struct Story: Codable, Equatable {
    var done: [String] = []     // 끝낸 장 id, 순서대로 (로그) — "well", "rage", "radio", "celebi"
    var at: String? = nil       // 열린 장
    var step = 0                // 0 도입 안 봄 · 1 추적 · 2 보스 준비
    var grunts = 0              // 이 장에서 이긴 조무래기 (라디오탑: 올라간 층)
    var dry = 0                 // 조무래기 없이 지난 레이더 (3이면 다음은 확정)
    var gruntsBeaten = 0        // 평생 조무래기 (카드) — 01의 `Walk.beaten`(관장 key 목록)과 헷갈리지 않게
    var doneAt = 0              // 마지막 장이 끝난 total 걸음 (간격 1,000)
    var scale: Bool? = nil      // 빨간비늘 (가방에 넣지 않음 — 넣으면 '팔기 · 전부'에 10W로 팔려 버림)
}
```

- **`Walk.version`은 절대 올리지 않는다** — `Store.load`가 버전이 다르면 세이브를 버리고 새로 시작함(= 사용자의 펫 소실).
- Swift 합성 `Decodable`은 기본값을 쓰지 않으므로 **나중에 `Story`에 더하는 필드는 전부 Optional**.
- 장 id는 문자열(인덱스 아님) — 장 순서를 바꾸거나 외전을 끼워도 세이브가 안 깨짐.
- 대사·장 정의는 코드(Story.swift)에, 세이브엔 진행 상태만.

## 8. 멀티 확장 여지

이야기 자체는 혼자 하는 것이 맞다. 대신 **같은 틀로 "외전"을 서버에서 받는** 쪽이 자연스럽다.

- **주간 로켓단 습격(비동기 협동)**: 작은 서버가 이번 주 간부(장 정의 JSON + 시드)를 내려줌 → 각자 싸움 → 이긴 기록을 올리면 공동 HP 풀이 줄고, 0이 되면 참가자 모두 보상. 03 레이드의 `dealt` 합산 모델과 같음(→ 03-raid.md §8). 친구 코드로 "우리 팀" 단위도 가능.
- **검증이 쉬운 구조**: 배틀은 `begin`에서 받은 시드 + 고른 명령만으로 재현됨(`Beat` 재생). 단 지금은 `turn`마다 뷰의 `rng`에서 새 시드를 받음 → 03의 `fightRng` 분리가 먼저(→ 03-raid.md §5). `(시드, 양쪽 파티 스냅샷, 명령 목록)`만 올리면 서버가 다시 돌려 승패를 확인 → 치팅 걱정 적음.
- **친구 카드**: 친구의 `done` 목록·`gruntsBeaten`을 트레이너 카드에 표시(읽기 전용).

**지금 해 둘 것 (비용 0)**: ① 장 id를 문자열로, ② `Chapter`/`Line`을 JSON으로 옮길 수 있는 평범한 값 타입으로, ③ 보스 파티를 `Seeded(fnv(id))`로 결정적으로(Swift `hashValue`는 실행마다 달라서 금지). 서버·친구 코드·명령 기록은 **지금 만들지 않는다**.

## 10. 리스크 · 열린 질문

**리스크**
- `after()`의 타워 분기, BattleView의 `indoor: b.trainer != nil` — 둘 다 "트레이너 = 타워"를 가정. 분기 순서를 틀리면 이야기 배틀이 BP를 주거나 실내로 그려짐 → 셀프테스트로 막음.
- `.say`의 3초 자동 넘김을 대사에 쓰면 흘끗 보는 사용자는 다 놓침 → 대사는 반드시 새 `.story` 화면(당겨 보기, 로그로 다시 보기).
- 홈 배너로 카드 높이가 바뀜 — 대기 중에만 한 줄, 가장 긴 화면(포켓몬 472pt)보다 짧게.
- 원작 파티·레벨·세부 사건 순서는 기억에 의존한 초안 — 확정 전 Bulbapedia로 확인 필요(4절 "초안" 표시).

**결정할 것 (권장 기본값)**
1. **01보다 먼저 만들까?** → 권장: 01 뒤. 배지 트리거가 이야기의 뼈대. 급하면 폴백 W로 먼저 내고 01이 오면 자동 전환.
2. **이야기가 체육관을 막을까?** (원작: 아지트·라디오탑 해결 전 막히는 길이 있음) → 권장: **막지 않음**. 데스크 펫에서 강제 순서는 답답함.
3. **조무래기는 레이더에서만?** 아니면 배너에서 바로 싸우기? → 권장: 레이더(첫 발견 1/3, 4번째 확정). 평소 루프에 섞이는 게 핵심.
4. **이야기 배틀 파티**: 동료 혼자 vs 타워식 3마리 → 권장: 타워식 3마리(교체가 의미 있고 간부가 보스답게).
5. **빨간 갸라도스를 쓰러뜨리면 끝?** → 권장: 원작처럼 쓰러뜨리면 끝(빨간비늘은 줌), 도망·패배는 재도전.
6. **라디오탑 보상으로 칠색조 1회?** (상점은 9,999W로 계속 판매) → 권장: 예 — Lv.45·3V. 싫으면 BP 30으로 대체. 지금 README의 "칠색조 · 뮤츠는 상점에서만" 원칙을 깨므로 03 Q2와 같이 정함(→ README.md 열린 질문 4).
7. **이미 많이 진행된 세이브**: 1장부터 하루 한 장씩 vs 조건 맞는 장부터 → 권장: 1장부터 차례로, 장 사이 1,000걸음.
8. **대사 톤**: 원작 번역 인용 vs 새로 짧게 → 권장: 새로 짧게(이름·장소만 원작).
9. **에필로그 조건 "세레비 보유"가 너무 먼가?** (환상의 숲 = 도감 300) → 권장: 그대로. 클리어 후 목표로 두기 좋음.
10. **알림 기본값**: 새 장 알림 켬? → 권장: 켬(종류 "이야기", 우클릭 → 알림에서 끄기).
