# 5.0 화면 품질 패스

사용자 의견: "글자 겹침같은 문제 없게 ui 제대로 확인하고 전반적으로 이펙트가 좀 구려보이거든? 포켓몬 도트 외에 스킬 이펙트, ui 도트 개선도 한번 했으면 하고 하단 패널도 좀 개선할 부분 있는지 검토 한번 해봐"

앱 코드로 렌더한 화면이에요. 이펙트 · HP 바 · 패널 색 시안은 main 4db6221에 **꺼진 채로** 들어 있어요(`FX_V2=1`로 렌더).

## 1. UI 전수 확인 (적용 완료)

| 파일 | 내용 |
|---|---|
| `stress-1.png` ~ `stress-3.png` | 극단값 렌더 25장: 가장 긴 이름(포켓몬 · 기술 · 특성 · 메가 폼), 12자 ID, 9,999W · BP · 연승, 99,999,999걸음, 이로치 · ♀ · 지닌 도구 · 숨겨진특성 · 메가 · 상태 이상이 한꺼번에, 칭호 3개, 꽉 찬 목록 · 빈 목록 |
| `fix-mint-pick.png` | 민트 21개 고르기: 6줄씩 쪽 나누기, 고른 줄이 늘 보임, 버튼과 겹치지 않음 |

- 자동 검사를 아래 패널까지 넓혔어요. 렌더할 때 글자끼리 겹침, 창 밖으로 나감, 잘림(…), LCD 글자 겹침을 모두 출력해요. 지금 전체 화면(250여 장)에서 0건이에요.
- 자체 테스트는 글꼴을 15% 넓힌 경우로도 한 번 더 돌아요. 다른 OS 글꼴 차이를 미리 잡아요.
- 찾아서 고친 것:
  - 회사 Mac의 도감 업적 넘침 · ✦ 겹침
  - 민트 고르기의 스크롤 · 버튼 겹침
  - LCD 배틀 머리줄의 이름 겹침(긴 이름 + 상태 이상이면 레벨부터 빼서 한 줄에 맞춤)
  - HP 상자의 "…" 하나만 남던 도구 표시
  - 메뉴 배틀 묶음 줄 잘림
  - 목록 아이콘이 모두 같은 "+"이던 것 → 실제 아이템 그림

## 2. 기술 이펙트 (시안: 6개 GIF)

`fx/<기술>.gif`: 왼쪽은 지금, 오른쪽은 개선안이에요. `-before-strip.png` · `-after-strip.png`는 8프레임 정지 그림이에요.

| 파일 | 기술 | 개선안 |
|---|---|---|
| `fx/053.gif` | 화염방사 | 커지며 쏟아지는 불꽃 줄기, 맞으면 몸을 감싸는 불길과 주황 빛 |
| `fx/056.gif` | 하이드로펌프 | 굵은 물줄기, 맞으면 물방울 왕관과 파문 |
| `fx/085.gif` | 10만볼트 | 하늘에서 떨어지는 번개 세 줄기, 화면 번쩍임, 맞으면 몸이 노랗게 깜빡 |
| `fx/058.gif` | 냉동빔 | 얼음 결정이 실린 빔, 몸에 얼음이 자라다 깨져 흩어짐 |
| `fx/247.gif` | 섀도볼 | 연기 꼬리가 달린 구, 어두운 파동 고리 |
| `fx/033.gif` | 몸통박치기(모든 접촉 기술) | 돌진 속도선, 큰 타격 별, 발밑 먼지 |

- 공통: 맞는 순간 상대가 하얗게 두 프레임 번쩍이고 화면이 흔들려요(효과 굉장 · 급소면 더 세게).
- 타격 프레임 정지(hit stop)는 대사 · 타이밍과 맞물려서 적용 단계에서 넣을게요.
- 외부 소스 검토:
  - 쇼다운 배틀 이펙트 그림은 쇼다운 저장소에 라이선스가 따로 적혀 있지 않은 팬 그림이 섞여 있어요.
  - LCD 해상도(192×128)에 맞추려면 어차피 다시 그려야 해서, 앱 안에서 도트로 그리는 쪽을 추천해요.
