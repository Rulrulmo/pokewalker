# 5.0 상단 LCD 꾸미기 시안

앱에 실제로 넣은 시험 코드로 렌더한 화면이에요(그린 그림이 아니에요). 고른 시안 하나로 전체 화면에 적용해요.

## 2차-B 적용 · 수정 (723f1ae)

사용자가 2차-B를 골랐어요. 모든 LCD 화면에 적용하고 다섯 가지를 고쳤어요. 보드는 행마다 지금 / 2차-B 수정 전 / 2차-B 수정 후예요.

| 파일 | 내용 |
|---|---|
| `r3-board.png` | 대표 화면 8개 (컬러) |
| `r3-board-grey.png` | 같은 보드, 회색 LCD |
| `r3-board-fixes.png` | 고친 곳: 포켓몬 겹침(도감 메가 · 거래소 · 교환 제안), 안내 카드(보상 · 로딩), 선택 줄(상점 · 기술 · 로토무) |
| `r3-board-mega.png` | 메가 레이드: 로비(0/20 · 19/20) · LCD만 · 난이도 · 20승 지급 카드 · 확률 획득 카드 (꾸밈 끔 / 2차-B / 회색) |
| `r3-board-more.png` | 레이드 · 메가 난이도 · 배틀 타워 · 트레이너 카드 · 교환 · 가방 · 우편함 · 코스 |

1. **포켓몬 겹침:** 화면마다 글자 패널 왼쪽 무대에 맞춰 크기(최대 1.15배)와 위치를 정해요. 무대 밖으로는 그리지 않아서 애니메이션 중에도 글자 · 띠 · 패널에 닿지 않아요. 자동 검사가 있어요: 전체 그림 886개가 무대에 맞는지, 큰 포켓몬(갸라도스 · 고래왕 · 루기아 · 레쿠쟈 · 메가리자몽Y 등) 화면에서 겹침이 없는지 확인해요.
2. **안내 카드:** 카드 크기를 글자에 맞추고, 긴 줄은 한 단계 작은 글씨로 써요. 별 · 마크 · 굵은 테두리는 없앴고, 얇은 테두리와 위쪽 색 줄로만 종류를 나타내요(보상 금색 · 경고 주황 · 로딩 파랑). 뒤 풍경은 흐리게 했어요.
3. **선택 줄:** 패널 안에만 그리고, 묶음 색(상점 주황 · 포켓몬 초록 · 우편 파랑 …)에 둥근 모서리예요. 줄 위 글자는 진한 색이에요. 가로 구분선도 패널 안으로 넣었어요.
4. **스톤 고르기 → 스톤 지급 카드 (3a9c16b):** 규칙이 보스별 20승 자동 지급으로 바뀌어서 고르기 화면은 없앴어요. 스톤이 오면(20승이든 확률이든) 판 결과 다음에 금색 보상 카드가 떠요. 왼쪽에 그 스톤이 크게 빛나고, 오른쪽에 "같은 보스 20승! / 행운의 메가스톤! · ○○나이트를 · 얻었다! · 우편함에서 받아요"가 나와요. 로비 · LCD · 메뉴는 보스마다 "스톤까지 n/20"(가졌으면 "스톤 보유")이에요. → `r3-board-mega.png`
5. **글자색:** 컬러 화면에서는 검정 대신 묶음 색의 진한 색이에요(띠 위 제목 포함). 회색 글씨도 묶음 색이 도는 회색이에요. 회색 LCD는 그대로라 잘 읽혀요.

- 귀퉁이 장식은 포켓몬 · 패널과 겹쳐서 뺐어요. 코스 화면에도 띠와 마크(지도 핀)를 붙였어요.

## 2차 시안 (시안 2 기반, 강도 2단계)

| 파일 | 내용 |
|---|---|
| `r2-board.png` | 대표 화면 8개 × 지금 / 시안 2 / 2차-A / 2차-B (컬러 화면) |
| `r2-board-grey.png` | 같은 보드, 회색 LCD("원작" 화면 설정) |
| `r2-board-more.png` | 스톤 고르기 · 메가 난이도 · 레이드 난이도 · 안내(보상) · 안내(로딩) · 배틀 타워 · 트레이너 카드 · 교환 |
| `r2-board-lists.png` | 목록 화면(가방 · 기술 · 우편함): 꾸밈 없이 그대로인지 확인용 |
| `4-r2a-<화면>.png`, `5-r2b-<화면>.png` | 한 장씩. 끝에 `-grey`면 회색 LCD |

- **2차-A (차분)**: 시안 2의 색 띠에 묶음 마크(몬스터볼 · 도감 · 친구 · 편지 · 가방 · 타워 · 레이드 · 메가 키스톤 · 카드)를 붙였어요. 포켓몬 뒤 왼쪽 창에만 장소 그림(풀밭 · 연구소 책장 · 센터 · 편지지 · 마트 진열대 · 타워 · 동굴)이 들어가고, 글자는 흰 패널 위에 있어요.
- **2차-B (화려)**: 장소 그림이 LCD 전체에 깔리고, 네 귀퉁이에 틀 장식이 붙어요. 포켓몬이 조금 커져요(제목은 가리지 않게 아래로 내림). 레이드는 보스 타입의 날씨가 내려요(예: 에스퍼는 반짝이).
- **메가 레이드**: 두 시안 모두 무지개 고리가 돌고, 메가 문양이 보스 뒤에 깔려요. B는 메가진화 연출과 같은 무지개 줄기가 안쪽으로 모여요.
- **스톤 고르기**: 2차 시안에서는 고른 메가스톤이 오른쪽에 크게 나와요.
- **안내 문구**: 종류별로 카드가 달라요. 보상은 금색 테두리와 별, 경고는 주황 테두리와 ⚠, 로딩은 파란 테두리와 모래시계예요. B는 뒤에 풀밭 풍경이 깔려요.
- 글자는 그대로예요. 띠 위의 회색 글씨는 진하게 바꿨어요(예: 배틀 타워 "다음 보상 14연승"). 회색 LCD에서도 읽혀요.
- 목록 화면(상점 · 가방 · 기술 · 우편함)은 글자가 많아요. 그래서 A는 띠, 마크, 흰 패널만 붙고, B는 패널 뒤로 장소 그림이 은은하게 비쳐요.

- 시안 1 수첩: 홈과 같은 종이 무늬, 제목에 마스킹테이프, 포켓몬은 스티커(흰 테두리)
- 시안 2 게임(추천): 묶음별 색 띠(포켓몬 초록 · 친구 파랑 · 상점 주황 · 타워 회청 · 레이드 보라 · 메가 무지개 · 카드 빨강), 은은한 배경, 포켓몬 아래 받침과 빛
- 시안 3 도트: 포켓워커 원작처럼 점 무늬 띠와 점 그림자
- 레이드 · 메가 레이드는 세 시안 모두 왼쪽 동굴 창에 보스가 타입 색(메가는 무지갯빛)으로 빛나요
- 안내 문구는 가운데 카드(종이 쪽지 / 흰 상자 / 점선 틀)
