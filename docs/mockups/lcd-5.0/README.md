# 5.0 상단 LCD 꾸미기 시안

앱에 실제로 넣은 시험 코드로 렌더한 화면이에요(그린 그림이 아니에요). 고른 시안 하나로 전체 화면에 적용해요.

| 파일 | 내용 |
|---|---|
| `board.png` | 대표 화면 8개 × 지금 / 시안 1 수첩 / 시안 2 게임 / 시안 3 도트 (컬러 화면) |
| `board-grey.png` | 같은 보드, 회색 LCD("원작" 화면 설정) |
| `board-raid-tower-card.png` | 레이드 · 레이드 난이도 · 메가 레이드 · 난이도 · 스톤 고르기 · 레이드 승리 안내 · 배틀 타워 · 트레이너 카드 |
| `<시안>-<화면>.png` | 한 장씩. `0-now` 지금, `1-notebook` 수첩, `2-game` 게임, `3-dots` 도트. 끝에 `-grey`면 회색 LCD |

- 시안 1 수첩: 홈과 같은 종이 무늬, 제목에 마스킹테이프, 포켓몬은 스티커(흰 테두리)
- 시안 2 게임(추천): 묶음별 색 띠(포켓몬 초록 · 친구 파랑 · 상점 주황 · 타워 회청 · 레이드 보라 · 메가 무지개 · 카드 빨강), 은은한 배경, 포켓몬 아래 받침과 빛
- 시안 3 도트: 포켓워커 원작처럼 점 무늬 띠와 점 그림자
- 레이드 · 메가 레이드는 세 시안 모두 왼쪽 동굴 창에 보스가 타입 색(메가는 무지갯빛)으로 빛나요
- 안내 문구는 가운데 카드(종이 쪽지 / 흰 상자 / 점선 틀)
