## 2차(10-16): 사용자 답 반영

사용자 원문: "1. 코스 칸 안에 넣는데 코스 -> 코스 선택이 좀 어색하지 않나? 2. 그냥 한줄 늘리는게 낫지 않아? 3. 좋아 4. 좋아"

- 1 메뉴 위치: 칸 이름을 바꿨어요. ★"모험 ▸ 코스 · 전설 원정"이고, 이름만 다른 "탐험 ▸"과 원정에 칸을 따로 주는 안도 그렸어요(§1).
- 2 홈: '친구' 줄은 그대로 두고 여섯째 줄 "전설 원정"을 늘 둬요. 홈과 메뉴의 카드가 한 줄(22pt)만큼 길어져요(§4).
- 3 안 열린 원정 흐리게 미리 보이기, 4 쉐이미 밤 규칙 없음: 확정이에요.
- 더해진 결정(같은 날)
  - "전설 여정은 한번에 하나만": 원정 화면에 '지금' · '멈춤' · '시작 전'과 시작하기 · 바꾸기 · 이어 하기를 그렸어요(§2.1).

## 1. 메뉴 위치(2차)

메뉴 첫 쪽 8칸이 다 차 있어서, 원정은 어느 묶음 안에 들어가거나 다른 칸과 자리를 나눠야 해요.

| 안 | 모양 | 좋은 점 | 아쉬운 점 |
|---|---|---|---|
| **★ 모험 ▸** | "모험 ▸ 코스 · 전설 원정". 칸 설명은 "코스 · 전설 원정 / 상쾌한 들판"(지금 코스). 조립할 수 있으면 빨간 점과 "지가르데 셀 50/50" | 이름이 묶음 둘을 다 품어요. 원정은 거의 코스 걸음이에요 | 코스를 바꿀 때 한 번 더 눌러요 |
| 탐험 ▸ | 이름만 다르고 같아요 | | |
| 원정 칸 따로 | 첫 칸이 "모험 ▸ 포켓 레이더 · 코스", 둘째 칸이 "전설 원정" | 원정이 한 번에 열려요 | 레이더 · 코스가 두 번 눌러야 해요. 레이더는 홈 바로가기가 있지만, 숫자 키 1이 레이더에서 모험 묶음으로 바뀌어요 |

- 어느 안이든 홈의 "전설 원정" 줄을 누르면 원정 화면이 바로 열려요.
- 1차의 "코스 ▸ 코스"와 "기록 ▸"은 뺐어요.

## 2. 전설 원정 화면

도감 업적과 같은 틀이에요.

- 아래 패널: 원정마다 한 줄이에요. 전설 그림, 이름, 유형과 남은 날, 막대, 다음 할 일을 보여요.
  - 팀 이벤트 줄은 막대가 둘이에요: 팀 합계(빨강, 달성하면 금색), 내 걸음(파랑, 2만을 넘기면 초록 ✓).
  - 아직 안 열린 원정(배회 · 시련 11-16, 협동 · 스토리 12-07)은 그림자와 흐린 글로 "○○에 열려요"를 보여요.
    - 고를 것: 이렇게 미리 보여 줄지, 열릴 때까지 숨길지예요.
  - 고른 줄 아래에 두 줄 설명과 버튼(조립하기 / 칼로스 코스로)이 있어요.
- LCD: 고른 원정을 크게 보여요. 전설 그림, 이름, 막대, 숫자 세 줄이에요(도감 업적 LCD와 같아요).
- 위 오른쪽 "전설 n/19종"은 원정으로 받은 전설 수예요.

### 2.1 한 번에 하나(2차, 서버 72cd5c3)

- 개인 원정은 하나만 '지금' 진행해요. 팀 이벤트는 저절로 참여라 이 제한에서 빠져요.
- 원정마다 상태가 셋이에요(유형 칸에 붙어요).
  - **지금**: 걸음 · 레이더가 세는 하나
  - **멈춤**: 하던 진행(셀 수)이 그대로 남아요. 멈춘 동안은 세지 않아요.
  - **시작 전**(또는 끝냄)
- 버튼
  - 지금 원정이 없을 때 시작 전 원정: "시작하기"
  - 지금 원정이 있을 때 다른 원정: "바꾸기 · 지금 것은 멈춰요". 설명은 "원정은 한 번에 하나 · 지금: 지가르데", "바꾸면 지가르데는 멈추고, 나중에 이어 할 수 있어요"
  - 멈춘 원정: "이어 하기"(다른 원정이 지금이면 "이어 하기 · 지금 것은 멈춰요")
  - 포기 · 처음부터 다시는 없어요(서버 규칙).
- LCD: "● 시작하기" / "● 바꾸기" / "멈춤 · ● 이어 하기"
- 5.1에는 개인 원정이 지가르데 하나라서 "시작하기"와 "지금"만 나와요. 바꾸기 · 이어 하기는 5.2 미리보기로 그렸어요(배회).

## 3. 지가르데 셀

- 셀은 칼로스 코스를 **3,000걸음 걸을 때마다 1개** 모여요(남은 걸음은 이어져요). 칼로스 레이더에서도 가끔 나와요(서버 설계, main 6cdd4a9).
  - 원정 줄: "셀 23/50 · 다음 1,240걸음". LCD: "셀 23/50 · 다음 셀 1,240걸음".
  - 아래 설명: "칼로스 코스 3,000걸음마다 1개", "다음 셀까지 n걸음 · 지금 코스는 칼로스가 아니에요"와 "칼로스 코스로" 버튼.
  - 정확한 글과 숫자는 서버의 저장 · act 모양에 맞춰요.
- 하나 모일 때마다 홈에 "지가르데 셀을 모았다! · 24/50" 알림 카드가 떠요. 셀은 크게 그려요.
- 셀 그림은 원작 스프라이트가 없어서(PokeAPI에는 지가르데큐브뿐) 앱이 도트로 그렸어요.
  - 초록 육각 셀이에요.
- 셀은 가방 물건이 아니에요. 원정 진행 안의 숫자예요(서버 결정). 5.0 앱에서 팔리지 않아요.
- 50개가 모이면 원정 줄 · 메뉴에 빨간 점이 생기고, "조립하기"를 누르면 조립 장면이 나와요(약 5.5초).
  1. 셀이 화면 가장자리에서 빙글 돌며 가운데로 모여요.
  2. 초록 빛으로 합쳐지고 흰 빛이 번쩍여요.
  3. 지가르데가 빛 속에서 나와요(부화 · 진화 장면과 같은 방식).
  4. "지가르데를 상자에 보냈다!"

## 4. 홈 여섯째 줄 "전설 원정"(2차)

- '친구' 줄은 그대로 두고 여섯째 줄을 늘 둬요. 그래서 줄 수가 이벤트에 따라 바뀌지 않아요.
  - 팀 이벤트 중: 막대 + "비크티니 62% · 3일". 목표에 닿으면 금색 막대 + "달성!"이에요.
  - 이벤트가 없는 주: 가장 가까운 원정 진행. 막대 + "지가르데 셀 23/50", 50개면 "지가르데 조립할 수 있어요".
  - 누르면 원정 화면이 열려요.
- 높이: 홈 패널은 메뉴 키 · 홈 키로 오갈 때 카드 크기가 변하지 않게 메뉴와 같은 높이(446)예요. 한 줄(22pt)만큼 늘려 468로 했어요.
  - 메뉴도 같이 468이 돼요. 메뉴 아래 여백이 조금 늘어요.
  - 줄 간격을 줄이는 방법(22 → 19)도 있지만, 줄이 빽빽해지고 누르는 칸이 작아져서 늘리는 쪽을 골랐어요.
  - 가장 긴 화면(포켓몬 상자 508)보다 짧아서, 크기 메뉴의 '화면에 들어가는 크기'는 그대로예요.
- 확인: Mac 크기 2 · 3 · 4, 컬러 · 회색 · 백라이트 LCD, Windows 크기 2 · 3 · 4 · 회색(`exp-windows.png`)에서 겹침 · 잘림이 없어요.
- 메뉴: 모험 ▸ 칸과 전설 원정 줄에도 "비크티니 팀 62% · 셀 23/50"이 나와요.

## 5. 특성패치

지금 '누구에게 쓸까요' 흐름(민트 · 병뚜껑과 같아요)에 그대로 들어가요.

- BP 교환소 '육성' 탭에 100BP로 팔아요. 가방에서 "쓸 포켓몬 고르기"를 눌러요.
- 포켓몬을 고르면 위에 전후가 보여요: "특성 심록 → 엽록소(숨겨진특성)".
  - 반대로도 써요: "피뢰침 → 정전기"(숨겨진특성 → 1번)
  - LCD에는 지금 특성이 보여요.
- 숨겨진특성이 없는 종(뮤 등)은 흐리고 "숨겨진특성이 없어요"로 보여요.
- 쓰고 나면 "이상해꽃의 특성이 엽록소로 바뀌었다!"가 나오고, 포켓몬 화면에 "엽록소 · 숨겨진특성"으로 보여요.
- 그림은 원작 스프라이트가 PokeAPI에 없어서 앱이 도트로 그렸어요. 보라 패치에 별이에요.

## 6. 그라시데아꽃(쉐이미 스카이폼)

로토무카탈로그와 같은 '모습 바꾸기' 화면이에요.

- 상점 '기타' 탭에 3,000W로 팔아요(한 번만 사는 중요한 물건).
- 쉐이미 화면의 ● 메뉴에 "모습"이 생기고, 아래 패널에 "모습 바꾸기"가 생겨요.
- 랜드폼 ↔ 스카이폼(풀 · 비행, 특성 하늘의은총)을 골라요. 폼 그림과 데이터는 5.0에 이미 있어요.
- 원작의 '밤 · 얼음 상태에서 랜드폼으로 돌아감'은 넣지 않았어요(지금 앱에 밤 규칙이 없어요).
- 같은 화면을 5.2의 비추는거울(토네로스 · 볼트로스 · 랜드로스)과 굴레의항아리(후파)가 써요.

## 8. 레이드 매일 교대(plan 20, 2차)

사용자: "레이드는 하루 파워 두개는 기본으로 주자 bp는 그냥 유지해줘 메가스톤 보장은 그대로 적용시점은 5.1이랑 같이"

- 로비 머리말: "오늘의 보스 · 루기아"와 오른쪽 "내일 칠색조". 창 제목도 "내일 칠색조"(지금은 "다음 주 X")예요.
  - 메가는 머리말 오른쪽이 "자정까지 9시간"이고, 창 제목이 "내일 메가갸라도스 · 메가앱솔"이에요.
- 파워 칸: 하루 10칸을 한 줄로 그려요(0시에 2칸, 1만 걸음마다 +1, 하루 상한 10, 남은 칸은 0시에 사라짐, 서버 72cd5c3).
  - "파워 4칸 · 오늘 2판 · 다음 칸까지 3,200걸음"
  - 0시 직후에는 기본 2칸이 차 있어요.
  - 하루 3판의 점은 없앴어요(하루 10판까지).
- 자정 안내: 버튼 위 줄에 "자정까지 9시간 · 남은 파워는 0시에 사라지고 2칸부터 다시". 그래서 친구 목록은 4줄이고, 내가 4등 밖이면 4번째 줄이 나예요.
  - 자정 3시간 전부터 이 줄이 강조색이 돼요.
  - 파워가 1칸 이상 남아 있으면 배틀 칸 · 레이드 줄에 빨간 점과 "파워 3칸 · 자정에 사라져요"가 나와요(지금의 '가득' 빨간 점 대신).
- LCD: "오늘의 보스 / n시간 남음 / 내일 칠색조 / 파워 n칸"
- 홈 레이드 줄: "오늘 루기아 · 파워 4칸"(자정 3시간 전부터 "· 2시간").
- 그대로인 것: 주간 우편, 친구 '이번 주' 탭과 순위, 내 이번 주 기록 칩("이번 주 4판"), BP, 메가 보스별 20승 확정.
- 화면에 안 보이는 일(5.1 코드)
  - 자정에 로비를 다시 받기. 서버가 "보스가 바뀌었어요 / 다시 열어 주세요"로 거절하면 그 말을 보이고 로비를 다시 받아요.
  - 메가 시작에 (dex, form)을 같이 보내기
  - 가짜 서버 · 자체 점검 · 라이브 점검의 '주 · 3판 · 3칸' 가정 고치기(켜지면 today.max는 10)

## 9. 5.1에 같이 들어가는 것(시안 없음)

- 조사 바로잡기: "스카이폼(으)로 바꾸기"를 "스카이폼으로 바꾸기"로 고쳤어요(시안에 반영).
  - 같은 모양이 5.0 앱에 다섯 곳 더 있어서 5.1에서 같이 고쳐요.
    - "(으)로 진화" 두 곳(가방의 진화 도구)
    - "은(는) 가방으로" 두 곳(지닌 도구 바꾸기)
    - "와(과) 더 이상"(친구 끊기)

- 대전 버그 둘(사용자 확정)
  - 상대 쪽 앱에서 블레이드폼 · 달마모드 줄의 편과 말이 바뀌지 않던 것(Duel.flipped)
  - 대전에서 메가 버튼 숨기기
