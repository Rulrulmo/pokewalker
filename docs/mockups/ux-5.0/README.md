# 5.0 아래 패널 편의성 검토

사용자 의견: "하단패널 내가 원한건 디자인 뿐만 아니라 편의성도 개선했으면 했던건데 디자인만 변경했네"

앱 코드로 렌더한 화면이에요. 시안은 main f1818b5에 **꺼진 채로** 들어 있어요(`UX_V2=1`로 렌더).

| 파일 | 내용 |
|---|---|
| `ux-board.png` | 홈 · 메뉴 · 포켓몬 상자 · 상점 수량 · 도감, 각각 지금 / 개선안 |
| `fight-layout.png` | 배틀 화면 정리: 쓰이지 않던 옛 배치(stress_battle_lcd)를 지우고 실제 앱 배치 하나만 남김 |

## 0. 먼저 고친 것 (main 92ed235, 적용 완료)

- `stress_battle_lcd`는 실제 앱에서는 나오지 않는 옛 배치였어요. 아래 패널 없이 LCD만 쓰는 자체 테스트 기본값이에요.
  - 이 배치를 코드 · 렌더 · 검사에서 모두 지웠어요. 앞서 고친 LCD의 "○메가" 탭도 이 배치였어서 같이 사라졌어요.
- 실제 배치에서 큰 포켓몬이 HP 상자에 닿던 곳을 모두 없앴어요.
  - 정지 그림 72종이 1~2칸 닿았고, 애니메이션 프레임 206개가 상자 쪽으로 튀어나갔어요.
  - 그림 886개 전부와 애니메이션 프레임 전부를 재는 검사를 넣었어요.
- 전체 렌더 266장에서 글자 겹침 · 잘림(…) · 넘침이 0건이에요. 긴 줄은 "…" 대신 덜 중요한 뒷부분부터 통째로 빼요.

## 1. 자주 하는 일 — 클릭 수 (홈에서 시작, 메뉴 키 포함)

| 할 일 | 지금 | 개선안 | 개선 방법 |
|---|---|---|---|
| 레이더로 잡기(바로 볼) | 4 (메뉴 → 포켓 레이더 → 덤불 → 볼) | **3** | 홈 바로가기 "레이더" |
| 함께 걷기 바꾸기(상자) | 5 (메뉴 → 포켓몬 → 칸 → 같은 칸 → 함께 걷기) | **3** | 홈 "포켓몬" + 고른 칸 아래 "함께 걷기" |
| 상처약 10개 사기 | 14 (메뉴 → 상점▸ → 상점 → 상처약 → + 아홉 번 → 사기) | **6** | 숫자를 눌러 10 입력, "최대" 버튼 |
| 이상한사탕 먹이기 | 8 (메뉴 → 포켓몬 → 도구 → 육성 → 사탕 → 쓸 포켓몬 고르기 → 피카츄 → 먹이기) | **6** | 홈 "도구" |
| 지닌 도구 주기 | 7 (메뉴 → 포켓몬 → 칸 → 같은 칸 → 도구 주기 → 도구 → 지니게 하기) | **5** | 고른 칸 아래 "도구 주기" |
| 기술 바꾸기 | 7 (메뉴 → 포켓몬 → 칸 → 같은 칸 → 바꾸기 → 칸 → 기술) | **6** | 고른 칸 아래 "자세히" |
| 우편 모두 받기 | 3 (메뉴 → 우편함 → 모두 받기) | **2** | 홈 "우편함"(빨간 점) |
| 배틀 타워 도전 | 4 (메뉴 → 배틀▸ → 배틀 타워 → 도전) | **2** | 홈의 "배틀 타워" 줄 → 도전 |
| 레이드 도전 | 7 (메뉴 → 배틀▸ → 레이드 → 도전 → 난이도 → 출전 고르기 → 도전) | **5** | 홈의 "레이드" 줄, 메뉴가 마지막 타일 기억 |
| 도감에서 한카리아스 찾기 | 7~16 (메뉴 → 기록▸ → 도감 → (신오 탭) → 쪽 넘기기 → 칸 → 같은 칸) | **3** | 홈의 "도감" 줄 → 찾기 → 이름 입력 |
| 메가스톤 지니기 | 7 (도구 주기와 같음) | **5** | 고른 칸 아래 "도구 주기" |

- 열한 가지 합계: **지금 66~75번 → 개선안 46번**(약 35% 줄어요).
- 키보드 단축키(아래 8)를 쓰면 더 줄어요.
