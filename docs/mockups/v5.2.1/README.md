# 5.2.1 시안: 포켓몬 즐겨찾기(10-23)

사용자 원문: "하다보니까 포켓몬 메뉴에 즐겨찾기 기능 있었으면 좋을것같긴한데 어때?" → "ㅇㅇ", "추천대로 10-26 뒤에 하자"

서버 설계는 main의 docs/plans/25-favorites.md(331c6f4)예요.
- 저장은 `Mon.fav`이고, 바꾸는 act는 `.mon(op: .fav(uid:, on:))`예요.
- 하나 놓아주기는 서버가 막아요.
- 중복 놓아주기는 서버와 앱이 같은 `releasableDuplicates`로 세어서 즐겨찾기를 빼요.

화면은 앱 코드로 직접 렌더했어요. 5.2 위에 시안용 시험 코드를 얹었고, 시험 코드는 main에 넣지 않았어요.
- 설정: 컬러 LCD, 크기 2, 2x
- 예시 저장은 5.2 시안과 같아요: 이상해꽃 Lv.55, 워커에 배루키 · 피카츄 · 이브이
- ★가 붙은 것이 추천안이에요.

## 표시

- ♥는 칸의 왼쪽 위에 분홍으로 그려요. 다른 표시와 겹치지 않아요.
  - ★ 이로치: 오른쪽 위
  - 지닌 도구: 오른쪽 아래
  - ◆ 3V: 왼쪽 아래
  - 진화 고르기 점(배루키)은 ♥가 있으면 ♥ 오른쪽으로 비켜요.
- 하트는 글자가 아니라 도형(원 둘 + 뾰족한 끝)으로 그려요. 그래서 Windows에서도 모양이 같아요.
- 이로치를 ★로 쓰고 있어서, 즐겨찾기는 ☆ 대신 ♡/♥로 했어요.

## 포켓몬 격자: ♥ 칩

- ★ 칩 옆에 ♥ 칩이 있어요. 누르면 찾기에 '즐겨찾기'가 들어가요(5.2의 ★와 같은 방식).
  - 찾기 칸이 "✕ 즐겨찾기"가 되고, 한 번 더 누르면 풀려요.
  - 찾기에 '♥'나 '즐겨찾기'를 직접 써도 되고, '♥ 물'처럼 다른 말과 같이 써도 돼요.
- ★ 정렬 이름을 줄여요: 번호순 · 레벨순 · V순 · 최근 → 번호 · 레벨 · V · 최근
  - ♥ 칩이 들어갈 자리가 없어서예요. 이름을 그대로 두면 '번호순'이 칸 밖으로 나와요(그림 5번째).
  - 파티 고르기의 정렬 이름은 칩이 없으니 그대로 둬요.

## 포켓몬 페이지: ♡ / ♥

- ★ 버튼 줄 맨 앞에 정사각 버튼을 둬요.
  - 꺼져 있으면 회색 ♡, 켜져 있으면 분홍 ♥예요. 한 번 누를 때마다 켜고 꺼요.
  - 동료('함께 걷는 중'), 워커('상자로 보내기'), 상자('워커로 · 놓아주기') 모두 같은 자리예요.
  - 놓아주기 바로 옆이라, 아끼는 포켓몬인 게 눈에 들어와요.
- LCD 오른쪽 칸에 '즐겨찾기' 한 줄이 생겨요.
- 배틀이 걸려 있으면 ♡를 숨겨요. 서버가 배틀 중에는 거절하기 때문이에요.
- LCD ● 메뉴(함께 · 워커로 · 놓아주기 · 닫기)에는 넣지 않아요. 그 줄에 자리가 없어요.

## 놓아주기

- 서버가 ♥ 포켓몬의 하나 놓아주기를 막아요. 그래서 앱은 그 자리에서 바로 이어 가요.
- ★ '풀고 놓아주기'
  - ♥ 포켓몬에서 '놓아주기'를 누르면 LCD에 "풀고 놓아줄까?"가 나와요.
  - 버튼은 '아니오 · 풀고 놓아주기'가 돼요. 묻는 동안 ♥ 버튼은 숨겨요.
  - 고르면 앱이 즐겨찾기를 끈 뒤 놓아줘요(`.fav(on: false)` → `.release`).
- B: 서버 문구만 보여 주기
  - "즐겨찾기한 포켓몬이에요 / 먼저 풀어 주세요"만 나와요.
  - 사용자가 ♥를 직접 끈 뒤 다시 놓아줘요. 한 단계가 더 있어요.
- 중복 n마리는 ♥를 빼고 세요.
  - 남길 1마리(가장 좋은 것)는 지금처럼 골라요. ♥는 그 1마리와 상관없이 모두 남아요.
  - 그림의 피카츄 셋: 가장 좋은 Lv.9(1V)와 ♥ Lv.11이 남고, Lv.15만 나가요(중복 1마리).
  - 중복 놓아주기 확인 창에 "즐겨찾기(♥)는 모두 남고"를 넣고, 남는 포켓몬 앞에 ♥를 붙여요.

## 보낼 때 한 번 더 묻기(Mac 확인 창)

- 묻는 곳: 글 올리기 · 제안하기 · 1:1 교환 신청 · 1:1 교환 답하기
  - 확인 창: "꼬부기는 즐겨찾기한 포켓몬이에요" / "교환되면 … 즐겨찾기는 풀려요. 그래도 ○○할까요?"
  - 서버는 막지 않아요. 수락 전까지는 내리기 · 취소가 돼요.
- 도구도 지녔으면 창 하나로 같이 물어요. 지금 있는 "도구도 함께 가요" 창과 합쳐서, 두 번 묻지 않아요.
- 내 글의 '이 제안으로 교환'(수락): 지금 있는 "교환할까요?" 창에 한 줄만 더해요. 창이 하나 더 생기지 않아요.
- Windows도 같은 문구로 자기 확인 창을 띄워요.

4. 맡기기도 물을까요?
   - 맡기기는 즐겨찾기 그대로 돌아와요. 그래서 ★ 묻지 않기를 추천해요.
   - 계획 25는 묻는 쪽이에요. 그림에는 묻는 창도 넣어 뒀어요.
5. 파티 고르기 · 교환 고르기에도 ♥ 표시(★ 추천: 보이기)
